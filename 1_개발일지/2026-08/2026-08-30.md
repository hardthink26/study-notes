## block1 
### 1. 개념점검: proxy& current_user의 개념을 알아낸다. 

### 2.등장배경 :
1. authenticated user를 관리할 Flask-login이라는 extension을 이용한다. 
2. User model에 기본 인증 동작들을 수행할 클래스를 넣는다.
	->UserMixin이라는 클래스를 User model에 넣는다. 
3. flask_Login initialization, 로그인 페이지로 이동하도록 설정 
4. user_loader decorator등록 
	-> 여기서 current_user라는 객체에 현 사용자 정보가 등록된다. 
	

### 3.개념:
current_user = a proxy for the current user 
proxy란 무엇인가? 
1. 개념: 
	- use context-local variables 
2. 왜 쓰는가? 
	- 전역 변수로 지정될 시 각기 다른 사용자의 request가 각기 데이터에 영향을 주기 때문
