# 개발일지 

## block1 
### 1. 구현 목적: Flask app EC2 수동 배포 
- 로컬에서 실행하던 Flask 앱을 AWS에 배포합니다. 

### 2.개발흐름 :
1. Mac에서 이미지 준비 
	1. AWS CLI 설치 및 로그인 
	2. EC2의 x86_84에 맞춰 linux/amd64 이미지 빌드 
	3. ECR 프라이빗 저장소 생성 및 이미지 push 
2. EC2 실행 환경 준비 
	1. EC2 생성 및 접속 
	2. Docker 설치 ·시작 
	3. EC2에서 ECR 로그인 후 이미지 pull 
3. 서버 실행 시작 
	1. EC2에 myvol(volume)생성 
	2. DEV_DATABASE_URL을 볼륨 내부 데이터베이스로 지정 
	3. Compose 실행 
	4. Flask deploy 명령으로 새 DB초기화 
4. 외부 접속 연결 설정 
	1. EC2에 연결된 보안 그룹에서 TCP8000 허용 
	2. 접속 주소: http://http://52.63.86.35:8000 
	3. ip만 입력 시 앱 포트로 연결되지 않는다. 

### 3.병목점/이유: 
1. ECR 로그인 자격 증명 없음 
	- mac에서 AWS CLI로그인 
2. GetAuthorizationToken 권한 거부 
	- EC2역할에 ECR 읽기 정책 허용 
3. Linux/amd64 manifest 없음 
	- ARM Mac에서 amd64 대상으로 재빌드 
4. 간헐적인 외부 연결 지연 및 접속 거부 
	- 현재 조사 중 -> 보류
