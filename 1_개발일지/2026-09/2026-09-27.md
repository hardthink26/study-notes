### 1. 구현 목적: error handling 
**why?** 
 -  404 or 500은 플라스크가 내부적으로 에러 생성 및, HTML response를 반환한다.
 -> 하지만 API client는 response가 JSON format을 얻기를 원해서 혼란이 생긴다. 
**sol** 
- the format requested by the client에 근거해서 error handler가 response 형식을 채택하게 구현
