## block1 
### 1. 구현 목적: docker compose 작성 
- 왜 작성하는가? 
	- 수동으로 복잡한 scripts & long `docker`command 입력을 줄이기 위함 

### 2.개발흐름 :
[구현코드](https://github.com/hardthink26/review_app_project/blob/5a6530825a0adb39ab8f0998a3959623d9bfdd68/compose.yaml#L1-L15)
1. compose.yaml파일 작성 
	- 사용한 설정항목들
		- 서비스 이름 
		- image: 실행할 이미지의 이름을 지정한다. 
		- ports: 8000:5000(host8000번은 container5000번에 연결한다.)
			- define the port mappings between the host machine and the containers. 
		- env_file 
			- specify one or more files that container environment variables to be passed to the containers 
		- volumes 
			- 기존 볼륨을 /home/flasky/data에 연결하고 
			- `external: true`로 함으로써 기존 볼륨을 이용한다.

### 3.병목점/이유: 
1. image를 images로 잘못 작성 
2. `build: /home/flasky/Dockerfile`로 컨테이너 내부 경로 작성 
	- 틀린 이유 
		- build 명령어는 빌드 컨텍스트 폴더를 지정한다. 
		- 현재 프로젝트에서는 `.`을 사용한다. 
### 4. 구현 결과 
1. localhost:8000에서 기존 계정으로 로그인 
2. 재생성 컨테이너에서도 볼륨에 저장된 데이터가 유효함을 확인했다.
