### 1. Cloud Deployment 
- **what means host "in the cloud"?** 
	- the application is installed on one or more virtual servers 
- **more advanced deployment model** 
	- based on containers 
		- A container isolates an application in an image of the application and its environments. 
		- A container image includes the application  plus all the dependencies it needs to run. 
- **another deployment option** 
	- Platform as a Service(PaaS) 
		- A service provider offers a fully managed platform on which applications can run. 
		- All the application developer needs to do is upload the application code to the servers maintained by the provider.
		- Most PaaS providers offer ways to dynamically "scale" the application by adding or removing servers as necessary to keep up with the number of requests received.
