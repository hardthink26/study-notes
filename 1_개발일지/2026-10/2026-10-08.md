### 1. 구현 목적: Obtaining code Coverage report 

### 2.개발흐름 :
1. 두 가지의 함수를 제작합니다. 
	- 만약 환경변수가 coverage variable을 발견 시 coverage를 싱행하는 함수 
	- 커버리지를 싱행 중이고 환경변수가 1이면 재시작 + 리포트 제작 함수 
		- **왜 재시작을 해야만 하는가?** 
			- 앱이 global scope에서 코드가 실행이 됨 -> 늦음 -> 앱의 초기화 부분은 기록x 
			- 따라서 커버리지 싱행 시 다시 파일을 재시작하여 기록을 진행합니다. 

### 3.병목점/이유: 
1. 코드 작성 이후 리포트에서 확연히 낮은 mitt percentage를 보임 
	- 코드 내 특정 부분을 커버리지가 담지 못함 -> 초기 임포트 및 앱 초기화 부분을 놓쳐서 보인 기록으로 추정 -> 따라서 import 부분을 커버리지 이후로 옮겨서 작성 -> 18% 에서 66%의 커버리지 범위를 보임
