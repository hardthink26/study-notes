## the where clause 
### def. 
*the mechanism for filtering out unwanted rows from result set.*

### how 
- 기본 조건 하나로 필터링 
**example**
```sql
select title 
from film 
WHERE rating = 'G';
```

- 조건이 두개 이상이라면? -> or , and 활용 
**example**
```sql
SELECT title
FROM film
WHERE rating = 'G' OR rental_duration < 4;
```

## The group by and having clauses
### def.
**the group by**: column value에서 데이터를 group할 때 사용한다. 
### why? 
동일한 column value에서 같은 값들을 가진 row들을 하나의 group으로 묶는다. 

### def.
**having**: the group by랑 한 쌍으로 쓰인다. group화 된 데이터에서 필터하기 위함 

**example**
```sql
SELECT c.first_name, c.last_name, count(*)
FROM customer c 
INNER JOIN rental r 
ON c.customer_id = r.customer_id
GROUP BY c.first_name, c.last_name
HAVING count(*) >= 40; 
```

## the order by Clause
### def.
**the mechanism for sorting result set using either raw column data or expressions based on column data**

*example*
```sql 
SELECT c.first_name, c.last_name,
time(r.rental_date) rental_time
FROM customer c
INNER JOIN rental r 
ON c.customer_id = r.customer_id
WHERE date(r.rental_date) = '2020-12-31'
ORDER BY c.last_name;
```

**만약 기준을 추가하고 싶다면?**
```sql
...
ORDER BY c.last_name, c.first_name;
```


# Ascending versus Descending Sort Order 
---
- 디폴트 값은 ascending이다. 따라서 Descending을 적용할려면 desc keyword가 필요! 

**example**
```sql 
SELECT C.first_name, c.last_name,
time(r.rental_date) rental_time
FROM customer c
INNER JOIN rental r 
ON c.customer_id = r.customer_id
WHERE date(r.rental_date) = '2026-12-31'
ORDER BY time(r.rental_date) desc;
```

- 주로 랭킹을 매길 때 사용 

# Sorting via Numeric Placeholder 
--- 
### def 
만약 sorting에 select clause's column을 사용한다면, reference the columns by their position in the select clause. 
**example**
```sql 
SELECT c.first_name, c.last_name, time(r.rental_date) rental_time
# 각각 왼쪽부터 1, 2, 3의 position을 가집니다. 
...
ORDER BY 3 desc;# time(rental_date)를 기준으로 내림차순 정렬합니다. 
```

**caution**
- 만약 select의 값을 추가하여 postion이 바뀐다면 결과에 영향을 미칠 수 있음 주의!
