- 선언된 블록({}), 즉 함수 내부에서만 선언 변수 사용 가능
	- 같은 변수명을 사용하더라도 블록이나 함수가 다르면 별도의 저장공간을 확보하므로 전혀 다른 변수로 사용됨
- 여기서 사용 범위를 벗어난 경우에도 데이터를 공유할 수 있게 해주는 것이 포인터이다. 

### 메모리의 주소 
- 메모리
	- 데이터를 넣고 꺼내 쓰는 공간으로, 그 위치 식별 가능해야 함 
	- 메모리의 위치를 식별하는 주소 값은 바이트 단위로 구분 
	- 예시)
		- int형 변수 a가 메모리 100번지부터 할당이 되어있다면 100번지부터 103번지까지 4바이트에 걸쳐 할당됩니다. 
### 주소 연산자 
- 주소
	- 변수가 할당된 메모리 공간의 시작 주소를 의미 
	- 주소 연산자인 &을 사용합니다. 

### 포인터와 간접 참조 연산자 
- 메모리의 주소는 필요할 때마다 계속 주소 연산을 수행하는 것보다 한 번 구한 주소를 저장해서 사용하면 편리 
- 포인터가 변수의 메모리 주소를 저장하는 변수!!! 
	- 주소를 저장할 포인터도 변수처럼 선언하고 사용 
	- 선언할 때는 변수 앞에 \*만 붙입니다. 
```c
#include <stdio.h>
int main(void)
{

int a;

int *pa;
pa = &a;

*pa = 10 ;
printf("포인터로 a 값 출력: %d\n", *pa);

printf("변수명으로 a 값 출력: %d\n", a);

return 0;
}
```
- 주의 사항!!!
	- 포인터 선인시 자료형은 주소 위치에 있는 변수의 자료형을 적습니다. 
- 관계 표시 
	- pa -> a: 의미는 pa는 a를 가리킨다 
- 포인터가 가리키는 변수를 사용할 때는 포인터에 특별한 연산자를 사용하는데 이를 **간접참조연산자**라고 합니다. 

### const를 사용한 포인터 
- const예약어를 포인터에 사용하면 이는 가리키는 변수의 값을 바꿀 수 없음을 의미로, 변수에 사용하는 것과는 다른 의미를 지닙니다. 
```c
#include <stdio.h>
int main(void)

{

int a =10, b = 20;

const int *pa = &a;

printf("변수 a의 값: %d\n", *pa);

pa = &b;

printf("변수 b의 값: %d\n", *pa);

pa = &a;

a = 20;

printf("변수 a의 값: %d\n", *pa);

return 0;
}
```
- const의 의미 
	- pa가 가리키는 변수 a는 pa를 간접참조해 변경이 불가능 

## 포인터 이해하기 
- 포인터는 주소를 저장하는 일정한 크기의 메모리 공간입니다. 

### 주소와 포인터의 차이 
- 주소는 변수에 할당된 메모리 저장공간의 시작 주소 값 자체고, 포인터는 값을 저장하는 또 다른 메모리 공간입니다. 
- 따라서 특정 변수의 주소 값은 바뀌지 않지만, 포인터는 다른 주소를 대입해 그 값 변경 가능합니다. 
- 주소는 **상수**, 포인터는 **변수** 
- 주소도 포인터처럼 간접 참조 연산자를 쓸 수 있지만, 상수이므로 대입 연산자 왼쪽에 올 수 없습니다. 

### 주소와 포인터의 크기 
- 포인터도 저장 공간이므로 그 크기가 존재 
	- 포인터의 크기는 저장할 주소의 크기에 따라 결정되는데 크기가 클수록 더 넓은 메모리를 사용 가능 
- 주소와 포인터의 크기는 sizeof 연산자로 확인 가능합니다. 
```c
#include <stdio.h>

int main(void)
{

char ch;
int in;
double db;

char *pc = &ch;
int *pi = &in;
double *pd = &db;

printf("char형 변수의 주소 크기: %d\n", sizeof(&ch));
printf("int형 변수의 주소 크기: %d\n", sizeof(&in));
printf("double형 변수의 주소 크기: %d\n", sizeof(&db));

printf("char * 포인터의 크기: %d\n", sizeof(pc));
printf("int * 포인터의 크기: %d\n", sizeof(pi));
printf("double * 포인터의 크기: %d\n", sizeof(pd));

printf("char * 포인터가 가리키는 변수의 크기: %d\n", sizeof(*pc));
printf("int * 포인터가 가리키는 변수의 크기: %d\n", sizeof(*pi));
printf("double * 포인터가 가리키는 변수의 크기: %d\n", sizeof(*pd));

return 0;
}
```
- **모든 주소와 포인터는 가리키는 자료형과 관계없이 그 크기가 같다.**

### 포인터의 대입 규칙 
- 포인터는 가리키는 변수의 형태가 같을 때만 대입해야 한다. 
```c
#include <stdio.h>

int main(void)
{

int a =10;
int *p = &a;
double *pd;

pd = p;
printf("%1lf\n", *pd);

return 0;
}
```

- 형 변환을 사용한 포인터의 대입은 언제나 가능합니다. 

### 포인터를 사용하는 이유 
- 임베디드 프로그래밍을 할 때 메모리에 직접 접근하는 경우나 동적 할당한 메모리를 사용하는 경우에는 포인터가 반드시 필요합니다. 

### 포인터 없이 두 변수의 값을 바꾸는 함수가 가능할까? 
```c
#include <stdio.h>

void swap(void);

int main(void)
{
int a = 10, b = 20;

swap();

printf("a:%d, b:%d\n", a, b);

return 0;
}
void swap(void)
{

temp = a;
a = b;
b = temp;

}
```
- 함수 안에 선언된 변수명은 사용 범위가 함수 내부로 제한되므로 main 함수에 있는 변수 a, b는 다른 함수인 swap함수에서 그 이름을 사용할 수 없습니다. 

- **변수의 값을 인수로 주는 경우**
```c
#include <stdio.h>

void swap(int, int);

int main(void)
{

int a = 10, b = 20;

swap(a, b);

printf("a:%d, b: %d\n", a, b);

return 0;

}

void swap(int x, int y)
{

int temp;

temp = x;
x = y;
y = temp;

}// a = 10, b = 20으로 동일 
```
- swap함수 호출 시에 main함수의 변수 a, b의 값이 복사되어 parameter x, y에 저장됨
- swap함수 안에서는 a, b의 복사본을 바꾸므로 main함수의 두 변수의 값은 변함없음
