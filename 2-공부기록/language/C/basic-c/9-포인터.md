- 선언된 블록({}), 즉 함수 내부에서만 선언 변수 사용 가능
	- 같은 변수명을 사용하더라도 블록이나 함수가 다르면 별도의 저장공간을 확보하므로 전혀 다른 변수로 사용됨
- 여기서 사용 범위를 벗어난 경우에도 데이터를 공유할 수 있게 해주는 것이 포인터이다. 

### 메모리의 주소 
- 메모리
	- 데이터를 넣고 꺼내 쓰는 공간으로, 그 위치 식별 가능해야 함 
	- 메모리의 위치를 식별하는 주소 값은 바이트 단위로 구분 
	- 예시)
		- int형 변수 a가 메모리 100번지부터 할당이 되어있다면 100번지부터 103번지까지 4바이트에 걸쳐 할당됩니다. 
### 주소 연산자 
- 주소
	- 변수가 할당된 메모리 공간의 시작 주소를 의미
