- **프로그램** 
	- CPU가 처리하는 명령어의 묶음 
- **연산자** 
	- 컴파일되면 명령어로 바뀜 
	- 피연산자 기준으로 구분이 가능합니다. 
		- 1개면 단항 
		- 2개면 이항 연산자 
		- 3개면 삼항 연산자 

### 산술 연산자와 대입 연산자 

- **산술 연산자** 
	 - 더하기,빼기, 등의 연산을 의미 

- **대입연산자** 
	- 오른쪽 수식의 결과를 왼쪽 변수에 저장합니다. 

- **나누기 연산자와 나머지 연산자** 
	- 나누기 연산자인 /를 사용합니다. 
```c
int main(void)
{
double apple;
int banana ;
int orange;

apple = 5.0/ 2.0;

banana = 5/ 2;

orange = 5 % 2 ;

printf("apple: %.1lf\n", apple);
printf("banana: %d\n", banana);
printf("orange: %d\n", orange);

return 0;

}
```
- 실수 연산에는 나머지의 개념이 없으므로 나머지 연산자와 피연자로는 반드시 **정수**만을 사용!!! 

### 증감 연산자 
- 하나의 연산자로 대입연산까지 수행하므로 변수의 값을 1씩 증가시키거나 감소시킬 때 사용 
```c 
#include <stdio.h>

#include <string.h>

  

int main(void)

{
int a = 10, b = 10;

++a; //변수의 값을 1씩만 증가 

--b; //변수의 값을 1만을 감소 

printf("a: %d\n", a);

printf("b: %d\n", b);

return 0;

}
```
- **주의** 
	- ++10과 같은 사용은 안됨 
		- 상수 10에 11을 저장할 수 없고 그 값을 바꿔서도 안되기 때문입니다. 

- **전위 표기와 후위 표기** 
	- 증감 연산자가 피연산자 앞에 놓이면 전위 표기(prefix): ++a 
	- 증감 연산자가 피연산자 뒤에 놓이면 후위 표기(postfix): a ++ 
- 차이점 
	- 전위표기는 값이 증감하고 나서 연산에 사용 
	- 후위표기는 연산에 사용하고 나서 값이 증감 

```c
int main(void)

{

int a = 5, b = 5;
int pre, post;

pre = (++a) *3;
post = (b++) *3;

printf("증감 연산 후 초깃값: a = %d, b = %d\n", a, b);
printf("전위형: (++a) * 3 = %d, 후위형: (b++) * 3 = %d\n", pre, post);

return 0;
}
```
- a++형태의 증감 연산자는 다른 연산자와 함께 사용시에 가장 마지막에 계산 

### 관계 연산자 

- 관계 연산자에는 대소 관계 연산자 또는 동등 관계 연산자 존재 

```c
int main(void)

{
int a = 10, b = 20, c = 10;
int res;

res = (a > b);

printf("a > b: %d\n", res);

res = (a >= b);

printf("a>=b: %d\n", res);

res = (a < b);

printf("a < b: %d\n", res);

res = (a <= b);

printf("a <= b: %d\n", res);

res = (a <= c);

printf("a <= c: %d\n", res);

res = (a != c);

printf(" a != c: %d\n", res);

return 0;
}
```

- 참이면 1, 거짓이면 0을 출력
