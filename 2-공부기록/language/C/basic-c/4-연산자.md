- **프로그램** 
	- CPU가 처리하는 명령어의 묶음 
- **연산자** 
	- 컴파일되면 명령어로 바뀜 
	- 피연산자 기준으로 구분이 가능합니다. 
		- 1개면 단항 
		- 2개면 이항 연산자 
		- 3개면 삼항 연산자 

### 산술 연산자와 대입 연산자 

- **산술 연산자** 
	 - 더하기,빼기, 등의 연산을 의미 

- **대입연산자** 
	- 오른쪽 수식의 결과를 왼쪽 변수에 저장합니다. 

- **나누기 연산자와 나머지 연산자** 
	- 나누기 연산자인 /를 사용합니다. 
```c
int main(void)
{
double apple;
int banana ;
int orange;

apple = 5.0/ 2.0;

banana = 5/ 2;

orange = 5 % 2 ;

printf("apple: %.1lf\n", apple);
printf("banana: %d\n", banana);
printf("orange: %d\n", orange);

return 0;

}
```
- 실수 연산에는 나머지의 개념이 없으므로 나머지 연산자와 피연자로는 반드시 **정수**만을 사용!!! 

### 증감 연산자 
- 하나의 연산자로 대입연산까지 수행하므로 변수의 값을 1씩 증가시키거나 감소시킬 때 사용 
```c 
#include <stdio.h>

#include <string.h>

  

int main(void)

{
int a = 10, b = 10;

++a; //변수의 값을 1씩만 증가 

--b; //변수의 값을 1만을 감소 

printf("a: %d\n", a);

printf("b: %d\n", b);

return 0;

}
```
- **주의** 
	- ++10과 같은 사용은 안됨 
		- 상수 10에 11을 저장할 수 없고 그 값을 바꿔서도 안되기 때문입니다. 

- **전위 표기와 후위 표기** 
	- 증감 연산자가 피연산자 앞에 놓이면 전위 표기(prefix): ++a 
	- 증감 연산자가 피연산자 뒤에 놓이면 후위 표기(postfix): a ++ 
- 차이점 
	- 전위표기는 값이 증감하고 나서 연산에 사용 
	- 후위표기는 연산에 사용하고 나서 값이 증감 

```c
int main(void)

{

int a = 5, b = 5;
int pre, post;

pre = (++a) *3;
post = (b++) *3;

printf("증감 연산 후 초깃값: a = %d, b = %d\n", a, b);
printf("전위형: (++a) * 3 = %d, 후위형: (b++) * 3 = %d\n", pre, post);

return 0;
}
```
- a++형태의 증감 연산자는 다른 연산자와 함께 사용시에 가장 마지막에 계산 

### 관계 연산자 

- 관계 연산자에는 대소 관계 연산자 또는 동등 관계 연산자 존재 

```c
int main(void)

{
int a = 10, b = 20, c = 10;
int res;

res = (a > b);

printf("a > b: %d\n", res);

res = (a >= b);

printf("a>=b: %d\n", res);

res = (a < b);

printf("a < b: %d\n", res);

res = (a <= b);

printf("a <= b: %d\n", res);

res = (a <= c);

printf("a <= c: %d\n", res);

res = (a != c);

printf(" a != c: %d\n", res);

return 0;
}
```

- 참이면 1, 거짓이면 0을 출력 

### 논리 연산자 
- 논리 연산자는 논리 관계를 판단하는 데 사용되며 &&, ||, !(not) 3가지 뿐입니다. 

- **caution** 
	- 10 < a < 30 vs (10 < a ) && (a < 20) 
		- 이 두 경우는 다른 결과를 도출할 수 있으므로 주의!!! 

### 숏 서킷 툴(short circuit tool)
- 좌항만으로 &&, || 연산 결과를 판별하는 기능 
- 불필요 연산을 줄여 실행 속도를 높일 수 있으나 예상치 못한 결과 제작 가능 

### 연산의 결괏값을 처리하는 방법 
- 연산을 실행 후 연산의 결괏값을 변수에 저장하지 않으면 값 버려짐 
- 따라서 연산 결과를 곧바로 사용하거나 대입 연산을 통해 다른 변수에 저장 


## 그 외 유용한 연산자 

### 형 변환 연산자 
- 피연산자를 하나 가지며 피연산자의 값을 원하는 형태로 변환 
	- 예시)
		- 정수를 실수로 혹은 실수를 정수로 변환 가능 
- 형 변환 연산자를 사용해 형태를 전환 시  피연산자의 값을 복사해 일시적으로 형태를 바꾸므로 연산 후 메모리에 남아있는 피연산자의 형태나 값은 그대로!! 
- **사용법**
	- `(자료형)피연산자` 
- 언제 사용? 
	- double같은 경우 저장 공간이 크고 연산 속도가 느리며 오차가 발생 따라서 int형을 기본으로 사용하고 실수 연산 결과 필요시만 형 변환해서 사용!! 
	- 실수에서 정수 부분만 추릴 시 사용 가능!!! 

### 자동 형 변환 
- 컴퓨터는 데이터의 형태에 따라 다른 연산 방법을 사용하므로 피연산자가 2개 이상이라면 피연산자의 형태는 같아야합니다. 
- 따라서 컴파일러는 컴파일 과정에서 피연산자의 형태가 다르면 형태를 일치시키는 작업 수행 => **자동 형 변환** 
- 사용 
	- 기본 규칙은 데이터 크기가 작은 값이 크기가 큰 값으로 바뀜 
		- 정수(4바이트)와 실수(8바이트)연산 시 정수가 실수로 자동 변환 
- **예상치 못한 값의 변형이 생길 수 있으니, 가능하면 피연산자의 형태를 같게 맞춰 사용!!** 

### sizeof 연산자 
- 피연산자를 하나만 사용할 수 있으며 피연산자의 크기를 바이트 단위로 계산 
- **사용법**
	-  `sizeof(피연산자)`: 
	- 피연산자의 대상은 변수, 상수, 수식, 자료형 등등 
	- 데이터의 크기를 확인하거나 메모리를 동적으로 할당하는 작업 등에 유용 
	- 괄호를 생략한 채 사용 가능 but, 수식이나 문자열 시 주의!!! 

### 복합대입 연산자 

- 연산 결과를 다시 피연산자에 저장할 필요가 있다면 추가로 대입 연산을 할 때 사용 
- -=, +=, %=, /=, *= 총 5 가지가 있습니다. 
- 대입 연산자의 특징을 그대로 가짐 
	- 왼쪽 피연산자는 반드시 변수가 와야 함 
	- 오른쪽 항의 계산이 모두 끝난 후, 즉 가장 마지막에 복합대입 연산자를 계산 

### 콤마 연산자 
- 한 번에 여러 개의 수식을 차례로 나열할 때 사용합니다. 
- 왼쪽부터 오른쪽으로 차례로 연산을 수행하며 가장 오른쪽의 피연산자가 최종 결괏값입니다. 
```c
int main(void)

{

int a = 10, b = 20;
int res;

res = (++a, ++b);/* 차례로 연산이 수행되어 결과적으로 res에 
저장되는 값은 증가된 b입니다.*/ 

printf("a:%d, b:%d\n", a, b);
printf("res:%d\n", res);

return 0;
}
```
- 콤마 연산자는 유일하게 대입 연산자보다 우선순위가 낮다.! 
	- if parentheses가 없는 res = ++a ++b;라면? 
		- res = ++a가 실행되고 후에 ++b가 실행됩니다. 
		-  = res = ++a; ++b 
		- **별개의 두 문장을 한 줄에 작성시에는 콤마연산자 대신 세미콜론(;)으로 구분** 
### 조건 연산자 
- 유일한 삼항 연산자로 ? 와 : 기호를 함께 사용합니다. 
- 조건 연산자는 첫 번째 피연산자가 참이면 두 번째 피연산자가 참이 되고, 첫 번째 연산자가 거짓이면 세 번째 피연산자가 결과값이 됩니다. 
- 사용 방법 
	- `(a > b) ? a : b`

### 비트 연산자 
- 데이터를 비트 단위로 연산합니다. 
- 비트 연산자에는 논리 연산을 수행하는 &,|, ^ 같은 비트 논리 연산자와 비트를 좌우로 움직이는 >>, << 같은 비트 이동 연산자가 존재 
- **사용처** 
	- 데이터를 비트로 정확히 표현 가능한 **정수**에만 사용이 가능합니다. 
- 비트 이동 연산자 
	- ex) a << 1 
		- a의 비트를 모두 왼쪽으로 한 비트씩 이동합니다. 이때 왼쪽으로 밀려나는 비트는 사라지고 오른쪽의 남는 비트는 0으로 채워집니다. 
	- ex) a >> 2
		- 2로 나눈 몫이 되며 이때 오른쪽으로 밀려나는 비트는 사라지며, 왼쪽의 남는 비트는 부호 비트로 채워짐 
		- 만약 자료형이 unsigned로 선언 시 부호 비트의 의미가 없으므로, 왼쪽의 남는 비트는 항상 "0" 

### 연산자 우선순위와 연산 방향 
- 하나의 수식에서 2개 이상의 연산자가 함께 쓰일 때는 연산자의 우선순위에 따라 연산 진행 
	- 단항 연산자 > 이항 연산자 > 삼항 연산자 순 
	- 산술 연산자 > (비트 이동 연산자) > 관계 연산자 > 논리 연산자 순 
	- 우선순위가 같거나 동일한 연산자를 반복해서 사용시 왼쪽부터 차례대로 연산
