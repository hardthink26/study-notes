# 11. 문자

문자 입력을 읽을 때는 **공백을 건너뛰는지**, **어디까지 읽는지**, **입력이 끝났는지**를 확인한다.

## ASCII 코드

ASCII는 문자와 제어 코드 128개에 0부터 127까지의 값을 대응시킨다. 숫자, 대문자, 소문자는 각 그룹 안에서 코드가 연속되고, 소문자의 코드가 대응하는 대문자보다 크다.

| 구분 | 예 | ASCII 값 |
| --- | --- | --- |
| 숫자 모양의 문자 | '0' ~ '9' | 48 ~ 57 |
| 대문자 | 'A' ~ 'Z' | 65 ~ 90 |
| 소문자 | 'a' ~ 'z' | 97 ~ 122 |
| 제어 문자 | 탭 (`\t`), 개행 (`\n`) | 9, 10 |

C 소스에서는 탭이나 개행을 이스케이프 시퀀스로 적을 수 있다. 예를 들어 `putchar('\n')`은 개행 문자 하나를 출력한다.

## scanf로 문자 읽기

`%c`는 다음 문자 하나를 그대로 읽는다. 서식 문자열에서 `%c` 앞에 공백을 넣으면 입력의 연속된 공백 문자를 먼저 건너뛴다.

| 호출 | 입력이 `A B`일 때 저장되는 값 |
| --- | --- |
| `scanf("%c%c", &ch1, &ch2)` | `ch1 = 'A'`, `ch2 = ' '` |
| `scanf(" %c %c", &ch1, &ch2)` | `ch1 = 'A'`, `ch2 = 'B'` |

공백 문자(whitespace)에는 스페이스, 탭, 개행 등이 포함된다. `%d`, `%lf`, `%s`는 변환 전에 선행 공백을 건너뛴다. 공백이나 개행 자체를 읽으려면 `%c` 앞에 공백을 넣지 않는다.

### scanf의 반환값

`scanf`는 값을 저장한 항목 수를 반환한다. 예를 들어 숫자가 필요한 자리에서 `%d`로 `x`를 만나면 0을 반환한다. 첫 변환이 완료되기 전에 입력이 끝나거나 읽기 오류가 발생하면 `EOF`를 반환한다. 값이 성공적으로 저장된 뒤에 사용하면 된다.

```c
#include <stdio.h>

int main(void)
{
    char ch;

    while (scanf("%c", &ch) == 1) {
        putchar((unsigned char)ch);
    }

    return 0;
}
```

## getchar와 putchar

- `getchar()`는 표준 입력에서 바이트 하나를 읽는다. 공백, 탭, 개행도 그대로 읽는다.
- 반환값은 `int`에 담는다. 읽기에 성공하면 바이트를 `unsigned char`로 해석한 값을 `int`로 반환하고, 입력이 끝나거나 읽기 오류가 나면 `EOF`를 반환한다. `int`로 받으면 `EOF`를 바이트 값과 구분할 수 있다.
- `putchar(ch)`는 표준 출력에 바이트 하나를 쓴다.

```c
#include <stdio.h>

int main(void)
{
    int ch = getchar();

    if (ch != EOF) {
        printf("입력한 문자: ");
        putchar(ch);
        putchar('\n');
    }

    return 0;
}
```


## 버퍼를 사용하는 입력 함수 
- 버퍼란? 
	- 프로그램에서 직접 할당하는 것이 아니라, 프로그램을 실행하는 중에 운영체제가 자동으로 할당하는 메모리의 저장 공간입니다. 
	- 키보드로 입력하는 데이터는 일단 버퍼에 저장된 후 scanf 함수에 의해 변수에 입력 
### scanf 함수가 문자를 입력하는 과정 
- 버퍼는 데이터를 저장하는 역할을 하므로 최초 입력할 때 필요한 데이터를 한꺼번에 저장해 놓으면 scanf 함수는 호출 즉시 버퍼에서 데이터를 가져올 수 있습니다. 
```c
#include <stdio.h>

int main(void)
{
char ch;
int i;

for(i=0; i<3; i++)
{

scanf("%c", &ch);
printf("%c", ch);

}
return 0;
}
```
- 이 예제는 문자를 입력하고 화면에 출력하는 과정을 세 번 반복합니다. 그러나 실행결과는 한 번의 키보드 입력으로 끝납니다. 
	- 최초 scanf 함수가 호출될 때 키보드로 문자열을 입력하면 일단 버퍼에 저장한 후 첫 번째 문자만 변수에 저장합니다. 
	- 두 번째 함수 호출부터는 버퍼에 남아 있는 문자열에서 차례로 다음 문자를 가져오므로 결국 새로운 키보드 입력이 필요없습니다. 
- **주의사항**
	- 입력 데이터는 엔터를 누르는 순간 버퍼에 저장되며 개행 문자도 함께 저장됩니다. 
- **입출력 함수가 버퍼를 사용하면 좋은 점**
	- 데이터를 안정적으로 입력받을 수 있습니다. 
	- 입력장치와 독립적으로 사용할 수 있습니다. 
		- 입력장치가 바뀌더라도 함수를 수정하지 않고 사용 가능
		- 버퍼와 입력장치를 연결하는 작업은 운영체제가 담당합니다. 
### scanf 함수 반환값 활용 
- 만약 개행 문자 또한 하나의 입력 데이터로 쓴다면 입력을 종료하는 별도의 신호가 필요 
- 이때 scanf 함수의 반환값을 사용합니다. 
```c
#include <stdio.h>

int main(void)
{

int res;
char ch;

while(1)
{

res =scanf("%c", &ch);
if (res == -1)break;
printf("%d ", ch);
}

return 0;
}
```
- scanf 함수는 기본적으로 입력한 값의 개수를 반환합니다. 
- 과정
	1. 키보드로 숫자를 입력하는 경우에도 일단 문자열의 형태로 버퍼에 저장됩니다. 
	2. 그 후에 문자열이 실제 연산이 가능한 값으로 변환되어 변수에 저장됩니다. 

### getchar 함수를 사용한 문자열 입력 
- getchar함수를 반복 사용하면 한 줄의 문자열을 char 배열에 입력할 수 있습니다. 

```c
#include <stdio.h>

void my_gets(char *str, int size);

int main(void)
{
char str[7];

my_gets(str, sizeof(str));
printf("입력한 문자열 : %s\n", str);

return 0;
}

void my_gets(char *str, int size)
{

int ch;
int i= 0;

ch = getchar();
while ((ch != '\n') && (i < size -1))
{
str[i] = ch;
i++;
ch = getchar();
}
str[i] = '\0';

}
```

### 입력 버퍼 지우기 
- scanf & getchar 함수는 같은 버퍼를 사용하며 입력 데이터를 공유합니다. 
- 따라서 앞서 실행한 입력 함수가 버퍼에 남겨 둔 데이터를 그 이후에 수행되는 함수가 잘못 가져갈 가능성이 있습니다. 
- 따라서, 버퍼에 남아 있는 불필요한 데이터는 미리 제거!!! 
- **방법**
	- 버퍼에 남아 있는 문자들을 모두 입력해서 사용하지 않고 버려라!!! 
```c
#include <stdio.h>

int main(void)
{
int num, grade;

printf("학번 입력: ");
scanf("%d", &num);//문자열은 정수로 변환되어 변수에 저장되고 버퍼에는 개행문자만 남습니다.
getchar(); //이 개행 문자가 이후의 입력에 영향을 줄 수 있으므로 함수를 호출해 제거 
printf("학점 입력: ");
grade = getchar();
printf("학번: %d, 학점: %c", num, grade);

return 0;

}
```
