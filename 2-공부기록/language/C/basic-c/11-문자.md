# 11. 문자

문자 입력을 읽을 때는 **공백을 건너뛰는지**, **어디까지 읽는지**, **입력이 끝났는지**를 확인한다.

## ASCII 코드

ASCII는 문자와 제어 코드 128개에 0부터 127까지의 값을 대응시킨다. 숫자, 대문자, 소문자는 각 그룹 안에서 코드가 연속되고, 소문자의 코드가 대응하는 대문자보다 크다.

| 구분 | 예 | ASCII 값 |
| --- | --- | --- |
| 숫자 모양의 문자 | '0' ~ '9' | 48 ~ 57 |
| 대문자 | 'A' ~ 'Z' | 65 ~ 90 |
| 소문자 | 'a' ~ 'z' | 97 ~ 122 |
| 제어 문자 | 탭 (`\t`), 개행 (`\n`) | 9, 10 |

C 소스에서는 탭이나 개행을 이스케이프 시퀀스로 적을 수 있다. 예를 들어 `putchar('\n')`은 개행 문자 하나를 출력한다.

## scanf로 문자 읽기

`%c`는 다음 문자 하나를 그대로 읽는다. 서식 문자열에서 `%c` 앞에 공백을 넣으면 입력의 연속된 공백 문자를 먼저 건너뛴다.

| 호출 | 입력이 `A B`일 때 저장되는 값 |
| --- | --- |
| `scanf("%c%c", &ch1, &ch2)` | `ch1 = 'A'`, `ch2 = ' '` |
| `scanf(" %c %c", &ch1, &ch2)` | `ch1 = 'A'`, `ch2 = 'B'` |

공백 문자(whitespace)에는 스페이스, 탭, 개행 등이 포함된다. `%d`, `%lf`, `%s`는 변환 전에 선행 공백을 건너뛴다. 공백이나 개행 자체를 읽으려면 `%c` 앞에 공백을 넣지 않는다.

### scanf의 반환값

`scanf`는 값을 저장한 항목 수를 반환한다. 예를 들어 숫자가 필요한 자리에서 `%d`로 `x`를 만나면 0을 반환한다. 첫 변환이 완료되기 전에 입력이 끝나거나 읽기 오류가 발생하면 `EOF`를 반환한다. 값이 성공적으로 저장된 뒤에 사용하면 된다.

```c
#include <stdio.h>

int main(void)
{
    char ch;

    while (scanf("%c", &ch) == 1) {
        putchar((unsigned char)ch);
    }

    return 0;
}
```

## getchar와 putchar

- `getchar()`는 표준 입력에서 바이트 하나를 읽는다. 공백, 탭, 개행도 그대로 읽는다.
- 반환값은 `int`에 담는다. 읽기에 성공하면 바이트를 `unsigned char`로 해석한 값을 `int`로 반환하고, 입력이 끝나거나 읽기 오류가 나면 `EOF`를 반환한다. `int`로 받으면 `EOF`를 바이트 값과 구분할 수 있다.
- `putchar(ch)`는 표준 출력에 바이트 하나를 쓴다.

```c
#include <stdio.h>

int main(void)
{
    int ch = getchar();

    if (ch != EOF) {
        printf("입력한 문자: ");
        putchar(ch);
        putchar('\n');
    }

    return 0;
}
```

## 입력 스트림과 버퍼

`scanf`와 `getchar`는 모두 표준 입력 스트림 `stdin`에서 읽는다. 일반적인 터미널에서는 Enter를 누르면 입력한 줄이 프로그램에 전달되고, 개행 문자도 함께 들어온다. 표준 입출력 라이브러리는 들어온 데이터를 버퍼에 보관할 수 있다.

예를 들어 `tiger`를 입력하고 Enter를 누른 뒤 `scanf("%c", &ch)`를 세 번 호출하면 차례로 `t`, `i`, `g`가 읽힌다. 각 호출 뒤 `printf("%c", ch)`로 출력하면 `tig`가 나오고, `e`, `r`, `\n`은 다음 입력 함수가 읽을 수 있게 남는다.

### 남은 개행 처리하기

`scanf("%d", &n)`으로 `42`를 읽으면 뒤의 개행이 남을 수 있다. 바로 `getchar()`를 호출하면 그 개행을 읽는다. 현재 줄의 나머지를 버리려는 경우 개행 또는 `EOF`까지 읽는다.

```c
int ch;

while ((ch = getchar()) != '\n' && ch != EOF) {
    // 현재 줄의 나머지를 버린다.
}
```

## getchar로 한 줄을 문자열에 담기

크기가 7인 배열에는 최대 6바이트와 문자열 종료 문자 `'\0'`을 저장할 수 있다. 다음 예제는 저장 공간이 가득 차면 그 줄의 나머지를 읽어 버린다. 개행이나 `EOF`를 만나면 루프를 끝낸다.

```c
#include <stddef.h>
#include <stdio.h>

// str은 size 바이트 이상의 배열을 가리킨다.
static void read_line(char *str, size_t size)
{
    if (size == 0) {
        return;
    }

    size_t len = 0;
    int ch;

    while ((ch = getchar()) != '\n' && ch != EOF) {
        if (len < size - 1) {
            ((unsigned char *)str)[len] = (unsigned char)ch;
            len++;
        }
    }

    str[len] = '\0';
}

int main(void)
{
    char str[7];

    read_line(str, sizeof str);
    printf("입력한 문자열: %s\n", str);
    return 0;
}
```

입력이 `abcdefghi`라면 배열에 `abcdef`와 `'\0'`이 저장된다. UTF-8에서 한글 한 글자는 여러 바이트를 사용하므로, 이 예제의 배열 한도는 바이트 기준이다.
