
### 아스키 코드 
- 128개의 문자를 0~127의 숫자 중에 각각 어떤 값으로 표현할지 정의한 것 
- **특징**
	- 알파벳과 숫자는 각각 연속된 아스키 코드 값을 갖는다. 
	- 소문자가 대문자보다 아스키 값이 크다. 
	- 제어 문자는 백슬래시와 함께 표시하며 출력할 때 그 기능을 수행한다. 
### scanf 함수를 사용한 문자 입력 
- scanf함수를 이용해 문자를 입력할 때는 %c 변환 문자를 사용합니다. 
	- %c는 알파벳이나 숫자 모양의 문자 등 형태가 있는 문자를 입력하지만 공백이나 탭 문자, 개행 문자와 같은 제어 문자도 입력하므로 주의!!! 
- **여러 개의 문자를 입력할 때 데이터를 구분하기 위해 칸을 띄우거나 탭을 사용하면 공백 문자나 탭 문자가 데이터로 입력될 수 있음을 기억!!** 

- **white space**
	- space bar ,Tab, Enter를 눌렀을 때 입력되는 문자를 묶어 이르는 말 
	- %d, %lf, %s와 같은 변환 문자로 숫자나 문자열을 입력할 때는 데이터를 구분하는 용도로 쓰이며, 그 자체가 데이터로 입력되지는 않습니다. 
- %c앞에 화이트 스페이스를 사용하면 문자도 분리해 입력할 수 있는 기능이 있습니다. 
	- `scanf(" %c %c", &ch1, &ch2);`
	- %c앞에 화이트 스페이스 중 아무거나 하나를 추가합니다. 

### getchar, putchar 함수 
- 만약 문자만 입력하는 경우에는 문자 전용 함수를 사용 
	- scanf함수는 문자뿐 아니라 숫자도 입력하는 기능이 포함되어 있으므로 문자만 입력하는 함수에 비해 크기가 큽니다. 
```c
#include <stdio.h>

int main(void)
{
int ch;

ch = getchar();
printf("입력한 문자: ");
putchar(ch);
putchar('\n');

return 0;
}
```
- getchar함수는 매개변수가 없으므로 괄호만 사용해 호출합니다. 
	- 호출된 함수는 키보드로 입력한 문자의 아스키 코드 값을 반환하므로 반환값은 int형 변수로 받습니다. 
	- scanf함수와 마찬가지로 공백 문자, 탭 문자, 개행 문자도 입력하는데 이들 문자를 제외하는 옵션은 따로 없습니다. 


## 버퍼를 사용하는 입력 함수 
- 버퍼는 프로그램에서 직접 할당하는 것이 아니라, 프로그램을 실행하는 중에 os가 자동으로 할당하는 메모리의 저장 공간입니다. 

### scanf함수가 문자를 입력하는 과정 
- 버퍼는 데이터를 보관하는 역할을 하므로 최초 입력할 때 필요한 데이터를 한꺼번에 저장해 놓으면 scanf함수는 호출 즉시 버퍼에서 데이터를 가져올 수 있습니다. 
```c
#include <stdio.h>

int main(void)
{

char ch;
int i;

for(i = 0; i < 3; i++)
{
scanf("%c", &ch);//tiger 입력 시,
printf("%c", ch);//-> tig 출력됨
}

return 0;
}
```
- 위의 코드는 문자를 입력하고 화면에 출력하는 과정을 세 번 반복 
	- 그러나 실행결과는 한 번의 키보드 입력으로 끝납니다. 
	- 두 번째 scanf함수 호출부터는 버퍼에 남아있는 문자열에서 차례대로 디음 문자를 가져옵니다. 

- **기억사항**
	- 입력 데이터는 **엔터**를 누르는 순간 버퍼에 저장되며 개행 문자도 같이 저장됩니다. 


### scanf함수 반환값 활용 
- 개행 문자 또한 하나의 입력 데이터로 쓴다면 입력을 종료하는 별도의 신호가 필요합니다. 
```c
#include <stdio.h>

int main(void)
{
int res;
char ch;

while (1)
{
res = scanf("%c", &ch);

if(res == -1) 
{
printf("%d ", ch);
}

return 0;
}
```
- 변환 문자는 코드화된 문자열을 숫자로 변환하는 방법을 scanf함수에 알려주는 역할을 합니다. 

### getchar 함수를 사용한 문자열 입력 
- getchar 함수도 버퍼를 사용하는 문자 입력 함수입니다. 
```c
#include <stdio.h>

void my_gets(char *str, int size);

int main(void)
{
char str[7];

my_gets(str, sizeof(str));
printf("입력한 문자열: %s\n", str);

return 0;
}

void my_gets(char *str, int size)
{
int ch;
int i =0;

ch = getchar();
while ((ch != '\n') && ( i< size -1))//배열의 크기를 넘는 문자열을 입력한 경우도 배열의 크기만큼 입력하도록 작성해 할당되지 않도록 합니다!! 
{
str[i] = ch;
i++;
ch = getchar();
}
str[i] = '\0';
}
```

### 입력 버퍼 지우기 
- scanf & getchar는 같은 버퍼를 사용하므로 입력 데이터를 공유합니다. 
- 따라서 앞서 실행한 입력 함수가 버퍼에 남겨 둔 데이터를 그 이후에 수행되는 함수가 잘못 가져갈 가능성이 있으므로 버퍼에 남은 불필요한 데이터는 미리 다 지우는 것이 좋습니다.
