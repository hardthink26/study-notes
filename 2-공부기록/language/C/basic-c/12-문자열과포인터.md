- 컴파일 과정에서 문자열은 첫 번째 문자의 주소로 둔갑하고 그 이후에는 배열을 출력하는 것과 같은 과정을 거칩니다. 
### 문자열 상수 구현 방법 
- 문자열의 크기는 일정하지 않습니다. 
	- 따라서 컴파일러는 문자열 상수를 독특한 방법으로 처리합니다. 
	- 컴파일 과정에서 문자열을 char 배열 형태로 따로 보관하고 문자열 상수가 있던 곳에는 배열의 위치 값을 사용합니다. 
```c
#include <stdio.h>

int main(void)
{
printf("apple이 저장된 시작 주소 값: %p\n", "apple");//주소 값 출력
printf("두 번째 문자의 주소 값: %p\n", "apple" + 1);//주소 값 출력 
printf("첫 번째 문자: %c\n", *"apple");//간접 참조 연산
printf("두 번째 문자: %c\n", *("apple" + 1));//포인터 연산식
printf("배열로 표현한 세 번째 문자 : %c\n", "apple"[2]);//배열 표현식 

return 0;
}
```
- 문자열 "apple"은 배열 형태로 따로 저장되고 printf함수의 인수로 그 첫 번째 문자의 주소가 사용됩니다.
	- p는 주로 포인터를 출력할 때 사용하는 변환 문자며 포인터 값을 16진수 대문자로 표현 
- 문자열은 컴파일 과정에서 char 변수의 주소로 바뀌므로 직접 포인터 연산을 수행할 수 있습니다. 
- **주의**
	- 주소로 접근해서 문자열을 바꾸면 안 됩니다!!! 
	- 예제) *"apple" = 't'; 
		- 연산 자체는 문제가 없으므로 정상적으로 컴파일되지만, 실행할 때 운영체제에 의해 강제 종료될 수 있습니다. 
			- 운영체제는 문자열 상수를 읽기 전용 메모리 영역에 저장합니다. 
### char 포인터로 문자열 사용 
- 문자열은 주소이므로 char 포인터에 대입해서 사용 가능합니다. 
	- 문자열을 char 포인터에 대입하면 문자열에 이름을 붙여 사용할 수 있고 다른 문자열로 쉽게 바꿀 수 있습니다. 
```c
#include <stdio.h>

int main(void)
{
char *dessert = "apple";

printf("오늘 후식은 %s입니다.", dessert);
dessert = "banana";
printf("내일 후식은 %s입니다.\n", dessert);

return 0;
}
```

### scanf 함수를 사용한 문자열 입력 
- 문자열 상수의 경우 값을 바꿀 수 없으므로 바꿀 수 있는 문자열을 원한다면 char 배열을 사용해야 합니다. 
-  scanf 함수 사용 
```c
#include <stdio.h>

int main(void)
{
char str[80];

printf("문자열 입력: ");
scanf("%s", str);
printf("첫 번째 단어: %s\n", str);
scanf("%s", str);
printf("버퍼에 남아 있는 두 번째 단어: %s\n", str);

return 0;
}
```
- scanf함수는 버퍼를 사용하므로 키보드로 입력한 문자열은 **enter** 를 누를 때 버퍼에 저장됩니다. 
	- 그 후에 scanf함수는 버퍼에서 문자열을 가져와 배열에 저장하는데 중간에 공백 문자, 탭 문자, 개행 문자가 있으면 그 이전까지만 저장합니다. 

### gets 함수를 사용한 문자열 입력 
- gets function은 중간의 공백이나 탭 문자를 포함해 문자열 한 줄을 입력합니다. 
```c
#include <stdio.h>

int main(void)
{
char str[80];

printf("문자열 입력: ");
gets(str);
printf("버퍼에 남아 있는 두 번째 단어: %s\n", str);

return 0;
}
```
- gets 함수는 키보드로 **enter**를 누를 때까지 입력한 한 줄을 char 배열에 저장합니다. 
	- 버퍼를 사용하므로 키보드로 입력한 데이터는 일단 버퍼에 저장된 후 gets함수가 가져갑니다. 
- 버퍼에는 개행 문자가 그대로 들어가지만, 배열에는 널 문자로 바뀌어 저장됩니다. 
- gets함수는 **enter** 만 눌러도 입력을 끝냅니다. 
	- scanf함수의 경우 문자열을 입력하기 전까지 space bar, enter, tab을 눌러도 계속 입력을 기다리는 상태를 유지합니다. 
		- 이들 키를 누를 때 입력되는 공백, 탭, 개행 문자는 문자열을 구분하는 용도로 쓰이며 실제 데이터로는 입력되지 않기 때문입니다. 
### fgets함수를 사용한 문자열 입력 
- scanf & gets함수는 입력되는 문자열의 크기가 배열 크기를 넘어설 위험성이 있습니다. 
- 안전하게 문자열을 입력하려면 배열 크기를 확인하는 fgets함수를 사용 권장 
	- fgets함수는 최대 배열의 크기까지만 문자열을 입력합니다. 
```c
#include <stdio.h>

int main(void)
{
char str[80];

printf("공백이 포함된 문자열 입력: ");
fgets(str, sizeof(str), stdin);
printf("입력된 문자열은 %s입니다.\n", str);

return 0;
}
```
- fgets의 구성 
	- 첫 번째 인수는 배열명 
	- 두 번째 인수는 배열의 크기를 알려줌 
		- 배열의 크기를 넘는 문자열을 입력해도 배열의 크기만큼만 저장 
	- 세 번째 인수는 stdin(standard input)
		- 데이터를 입력할 때 키보드와 연결된 표준 입력 버퍼를 사용하라는 뜻입니다. 
- fgets의 개행 문자 처리 방식 
	- 버퍼에 있는 개행 문자도 배열에 저장하고 널 문자를 붙여 문자열을 완성합니다. 
	- **개행 문자 제거 과정**
```c
#include <stdio.h>
#include <string.h>

int main(void)
{
char str[80];

printf("공백이 포함된 문자열 입력: ");
fgets(str, sizeof(str), stdin);
str[strlen(str)-1] = '\0';//개행 문자가 포함된 부분을 변경 
printf("입력된 문자열은 %s입니다.\n", str);

return 0;
}
```

### 표준 입력 함수의 버퍼 공유 문제 
- scanf & getchar 함수같은 표준 입력 함수는 입력 버퍼를 공유합니다. 
- 마찬가지로 gets & fgets 도 같은 버퍼를 공유하므로 문자열 입력 과정에서 문제 발생 가능 

```c
#include <stdio.h>

int main(void)
{
int age;
char name[20];

printf("나이 입력: ");
scanf("%d", &age);

printf("이름 입력: ");
gets(name);
printf("나이: %d, 이름: %s\n", age, name);

return 0;
}
```
- gets함수는 버퍼에서 개행 문자를 가져와 입력을 끝내므로 키보드로 이름을 입력하는 과정이 생략되어 name 배열의 첫 번째 요소에는 널 문자가 저장되어 아무것도 출력되지않습니다. 
- **개행 문자 지우는 방법** 
	- getchar(); 
	- scanf("%*c");
	- fgetc(stdin)
		- 버퍼에서 하나의 문자를 읽어서 반환, 반환 문자는 버림 
### 문자열을 출력하는 puts, fputs 함수 
- 화면에 문자열만을 출력할 때는 전용 출력 함수인 puts, fputs를 사용합니다. 
- 두 함수 모두 정상 출력된 경우 0을 반환하고 출력에 실패하면 -1(EOF)를 반환합니다. 
```c
#include <stdio.h>
int main(void)
{
char str[80] = "apple juice";
char *ps = "banana";

puts(str);
fputs(ps, stdout);
puts("milk");

return 0;
}
```
- puts 함수는 fputs함수와 달리 문자열을 출력한 후에 자동으로 줄을 바꿔주므로 편리하지만, 줄을 바꾸고 싶지 않을 때는 적당하지 않습니다. 

## 문자열 연산 함수 
### 문자열을 대입하는 strcpy 함수 
- char 배열은 문자열을 저장하는 변수의 역할을 하며 이를 문자열로 초기화할 수 있습니다. 
- **형태**
	- `strcpy(str1, str2);`
	- 복사할 문자열의 시작 위치를 알 수 있다면 어떤 것이든 두 번째 인수로 사용가능
	- 첫 번째 인수로 사용할 수 있는 값은 제한적입니다. 
		- char 배열이나 그 배열명을 저장한 포인터만 사용 가능합니다. 
	- **암기**
		- 첫 번째 인수로는 char 배열이나 배열명을 저장한 포인터만 사용 가능 
		- 두 번째 인수로는 문자열의 시작 위치를 알 수 있다면 어떤 것이든 사용 가능 
### 원하는 개수의 문자만을 복사하는 strncpy 함수 
```c
#include <stdio.h>
#include <string.h>

int main(void)
{
char str[20] = "mango tree";

strncpy(str, "apple-pie", 5);

printf("%s\n", str);

return 0;
}
```
- strncpy함수는 복사할 문자열에서 저장한 개수만큼 문자를 복사하고 널 문자는 저장하지 않습니다. 
- 만약 추가한 문자열만 출력하도록 쓸려면 복사한 후에 널 문자를 별도로 저장해야합니다. 
### 문자열을 붙이는 strcat, strncat 함수 
```c
#include <stdio.h>
#include <string.h>

int main(void)
{
char str[80] = "straw";

strcat(str, "berry");
printf("%s\n", str);
strncat(str, "piece", 3);
printf("%s\n", str); 

return 0;
}
```
- strcat 함수 사용 시 주의 사항 
	- **strcat 함수는 메모리를 침범할 수 있습니다.**
		- 붙여 넣을 공간의 주소를 증가시키므로 공간이 부족한 경우 할당하지 않은 다른 메모리의 영역을 침범할 수 있습니다. 
	- **strcat 함수를 사용할 때는 배열을 초기화해야 합니다.**
		- strcat 함수로 붙여 넣기 전에 먼저 널 문자의 위치를 찾으므로 반드시 초기화를 해야합니다. 
			- 배열이 초기화되지 않으면 쓰레기 값의 중간부터 붙여 넣을 가능성이 큽니다. 
			- **초기화 방식**
				- 특별한 문자로 초기화하거나 최소한 첫 번째 문자가, 널 문자가 되도록 초기화
				- `char str[80] = {'\0');`
				- `char str[80] = {0};`
				- `char str[80] = "";`
				- `str[0] = '\0'`
### 문자열 길이를 계산하는 strlen함수 
- 만약 배열에 저장된 문자열의 실제 길이를 알고 싶다면 사용!!! 
- `strlen(str)`
- **sizeof VS strlen**
	- sizeof 연산자는 배열에 저장된 문자열 길이와는 상관없이 배열 전체 크기를 계산합니다. 
### 문자열을 비교하는 strcmp, strncmp 함수 
- strcmp함수는 두 문자열의 사전 순서를 판단해 그 결과를 반환합니다. 
- `strcmp(str1, str2);
```c
#include <stdio.h>
#include <string.h>

int main(void)
{
char str1[80] = "pear";
char str2[80] = "peach";

printf("사전에 나중에 나오는 과일 이름: ");
if(strcmp(str1, str2) > 0)
printf("%s\n", str1);
else
printf("%s\n", str2);

return 0;
}
```
- strcmp함수는 두 문자열에서 우선 첫 문자의 아스키 코드 값을 비교합니다. 
	- 아스키 코드 값은 알파벳 순서에 따라 커지므로 아스키 코드 값이 크면 사전의 뒤에 나오는 문자열이 됩니다. 
	- 사전 순서를 판단한 결과는 반환값으로 알려줍니다. 
- strncmp함수는 비교할 문자 수를 세 번째 인수로 지정 가능합니다. 
- **주의**
	- strcmp 함수가 문자의 아스키 코드 값을 비교하므로 대소문자가 섞인 경우는 반환값이 사전 순서와 다를 수 있습니다. 
	- **strcmp 함수의 반환값으로 사전 순서를 판단할 때는 반드시 대소문자를 일치시켜야 합니다.**

## 연산 함수 직접 구현 
### 직접 만드는 strcpy함수
- **과정**
	1. strcpy함수는 포인터를 써서 문자열을 복사합니다. 
	2. strcpy함수는 문자열이 저장된 메모리에서 첫 번째 문자의 주소를 받습니다. 
```c
#include <stdio.h>

char *my_strcpy(char *pd, char *ps);

int main(void)
{
char str[80] = "strawberry";

printf("바꾸기 전 문자열: %s\n", str);
my_strcpy(str, "apple");
printf("바꾼 후 문자열: %s\n", str);
printf("다른 문자열 대입: %s\n", my_strcpy(str, "kiwi"));

return 0;
}

char *my_strcpy(char *pd, char *ps)
{
char *po = pd;
while(*ps != '\0')
{
*pd = *ps;
pd++;
ps++;
}
*pd = '\0';

return po;
}
```

### 직접 만드는 strcat 함수
