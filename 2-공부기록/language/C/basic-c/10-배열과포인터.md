- 배열은 자료형이 같은 변수를 메모리에 연속으로 할당
	- 따라서 각 배열 요소는 일정한 간격으로 주소를 갖게 됩니다. 
### 배열명으로 배열 요소 사용하기 
- 정수 덧셈 
	- 주소 + 정수 -> 주소 + (정수 * 주소를 구한 변수의 크기)
```c
#include <stdio.h>

int main(void)

{

int ary[3];
int i;

*(ary+0) = 10;
*(ary+1) = *(ary+0) + 10;

  

printf("세 번째 배열 요소에 키보드 입력: ");
scanf("%d", ary+2);

for(i=0; i<3; i++)
{
printf("%5d", *(ary+i));
}

return 0;

}
```
- 배열 연산을 사용할 때는 상황에 따라 대괄호나 포인터 연산식 중 적당한 것을 골라 사용 
	- 특별한 경우가 아니라면 대괄호를 사용하는 것이 편하며, &ary[2]와 같은 경우는 ary+2로 쓰면 연산 과정을 줄일 수 있다. 

### 배열명 역할을 하는 포인터 
- 배열명은 주소이므로 포인터에 저장이 가능 

```c
#include <stdio.h>

int main(void)
{

int ary[3];
int *pa = ary;
int i;

*pa = 10;
*(pa+1) = 20;
pa[2] = pa[0] + pa[1];//포인터에 대괄호를 사용 가능합니다. 이 경우 포인터 연산식으로 바뀌어 계산

for(i=0; i<3; i++)
{
printf("%5d", pa[i]);
}

return 0;
}
```

### 배열명과 포인터의 차이 
- 다른 점은 있습니다!!! 
- **sizeof**연산의 결과가 다릅니다. 
	- 배열명에 사용하면 배열 전체의 크기를 구하고 포인터에 사용하면 포인터 하나의 크기를 구합니다. 
- **변수와 상수의 차이가 존재**
	- 포인터는 그 값을 바꿀 수 있지만, 배열명은 상수이므로 값 바꿀 수 없습니다. 
```c
#include <stdio.h>

int main(void)
{

int ary[3] = { 10, 20, 30};
int *pa = ary;
int i;

printf("배열의 값: ");

for(i=0; i<3; i++)
{

printf("%d ", *pa);
pa++;

}

return 0;

}
```
- 포인터로 첫 번째 배열 요소를 출력하는 방법들 
	- pa를 배열명처럼 사용해 첫 번째 배열 요소를 출력하는 방법 
		- `printf("%d", pa[0])`
	- pa[0]를 그래도 포인터 연산식으로 바꾸는 방법 
		- `printf("%d", *(pa+0))`
	- *(pa+0)에서 의미 없는 0과 괄호를 없애는 방법*
		- `printf("%d", *pa)`

- **포인터로 배열의 데이터 처리 시 유의점**
	- 포인터의 값이 변할 수 있으므로 유효한 값인지 확인 필요 
		- 현재 pa에 배열에 할당된 영역의 주소를 가리키고 있다면 간접 참조 연산을 통해 그 공간이나 저장된 값을 사용해서는 안됨 
	- 포인터에 증가 연산자와 간접 참조 연산자를 함께 사용할 때 전위 표현 사용 안됨 

### 포인터의 뺄셈과 관계 연산 
- 가리키는 연산의 자료형이 같으면 포인터끼리의 뺄셈이 가능합니다. 
	- ` 포인터 - 포인터 = 값의 차 / 가리키는 자료형의 크기` 
```c
#include <stdio.h>

int main(void)
{

int ary[5] = { 10, 20, 30, 40, 50 };
int *pa = ary;
int *pb = pa + 3;


printf("pa: %d\n", pa);
printf("pb: %u\n", pb);
pa++;
printf("pb - pa: %u\n", pb - pa);

printf("앞에 있는 배열 요소의 값 출력: ");
if (pa < pb) printf("%d\n", *pa);
else printf("%d\n", *pb);

return 0;
}
```
- 뺄샘의 수행 
	- pb - pa = (40 - 32 / sizeof(int)) => 8/4 => 2 
	- 뺄셈 결과는 배열 요소 간의 간격차이를 의미합니다. 


## 배열을 처리하는 함수 
- 함수로 배열을 처리하려면 포인터가 필요!!! 

### 배열의 값을 출력하는 함수 
- 첫 번째 배열 요소의 주소만 알면 나머지 배열 요소는 포인터 연산으로 모두 사용 가능 
- 함수를 호출할 때는 배열명을 주고 함수의 매개변수로 포인터를 선언합니다. 
- 그리고 함수 안에서 포인터를 배열명처럼 사용
- 배열명 자체가 주소이므로 그 값을 함수의 인수로 주는 것은 얼마든 가능합니다.
```c
#include <stdio.h>

void print_ary(int *pa);

int main(void)
{

int ary[5] = { 10, 20, 30, 40, 50 };

print_ary(ary);

return 0;
}

void print_ary(int *pa)
{

int i ;

for (i=0; i < 5; i++)
{
printf("%d ", pa[i]);
}

}
```
- 동일한 배열의 데이터를 2개의 함수가 공유합니다. 
- 이와 같은 처리 방식은 배열에 있는 다량의 데이터를 다른 함수로 복사하지 않고 접근하므로 더 효율적입니다. 
	- 다만, 주소만 알면 해당 위치의 값을 바꿀 수도 있으므로 의도치 않게 값을 변형하지 않도록 합시다. 

### 배열 요소의 개수가 다른 배열도 출력하는 함수 
- 배열 요소의 개수가 바뀌면, 출력문의 반복 횟수가 달라지므로 함수의 수정이 불가피
```c
#include <stdio.h>

void print_ary(int *pa, int size);

int main(void)
{

int ary1[5] = { 10, 20, 30, 40, 50 };
int ary2[7] = { 10, 20, 30, 40, 50, 60, 70 };

print_ary(ary1, sizeof(ary1)/ sizeof(ary1[0]));
printf("\n");
print_ary(ary2, sizeof(ary2)/sizeof(ary2[0]));

return 0;
}

void print_ary(int *pa, int size)
{

int i;

for(i=0; i< size; i++)
{
printf("%d ", pa[i]);
}

}
```

### 배열에 값을 입력하는 함수 
- 입력 함수는 데이터를 저장할 배열의 위치가 필요하므로 함수 안에서 포인터를 직접 사용 
```c
#include <stdio.h>

void input_ary(double *pa, int size);
double find_max(double *pa, int size);

int main(void)
{

double ary[5];
double max;
int size = sizeof(ary)/ sizeof(ary[0]);

input_ary(ary, size);
max = find_max(ary, size);
printf("배열의 최댓값: %.1lf\n", max);

return 0;
}

void input_ary(double *pa, int size)
{

int i;

printf("%d개의 실수값 입력: ", size);
for (i=0; i< size; i++)
{
scanf("%lf", pa + i);
}

}

double find_max(double *pa, int size)
{
double max;
int i ;
max = pa[0];

for (i=0; i < size; i++)
{
if (pa[i] > max) max = pa[i];
}

return max;
}
```

### 함수의 매개변수 자리에 배열을 선언하는 경우 
- 함수의 매개변수 자리에 배열을 선언하면 배열의 저장공간이 할당되지 않으며, 배열명은 컴파일 과정에서 첫 번째 배열요소를 가리키는 포인터로 바뀝니다. 
	- 따라서 배열 요소의 개수와 무관하게 배열을 처리하는 함수를 만들려면 반드시 배열 요소의 개수를 따로 받아야 합니다. 

- **배열의 크기가 달라도 입출력을 할 수 있게 하려면 배열 요소의 개수를 알아야한다.**
