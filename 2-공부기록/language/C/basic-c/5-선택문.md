	- 종류
		- 선택문 
		- 반복문

## IF 문의 기본 형식 
- 기본 if문은 조건식을 만족하면 실행문을 실행하고, 만족하지 않으면 실행하지 않고 지나간다. 
- **작성 규칙**
	- if문은 중괄호를 사용하고 들여쓰기해 실행문을 명확히 구분
	- 실행할 문장이 두 문장 이상이면 반드시 중괄호로 묶어라 

### if ~else문 
- 언제 사용? 
	- 조건을 만족하지 못할 때 수행되는 실행문 작성 시 !!! 
- 작성 규칙 
	- if ~else문의 else에는 조건을 작성하지 않습니다. 
	- 실행할 문장이 두 문장 이상이면 반드시 중괄호로 !! 
	- 경우에 따라 if문을 2번 사용보단 if ~else한번에 끝내라 !! 

### if ~else if ~else 문 
- 3개 이상의 실행문에서 반드시 하나를 선택하는 경우 사용 
- **작성 규칙**
	- 각 조건에 따라 실행할 문장이 두 문장 이상이면 반드시 중괄호로 !! 
	- 조건식을 차례로 검사하므로 이전 조건의 결곽가 반영 
	- 순서가 중요하지 않다면 참이 될 가능성이 높은 조건식을 먼저 사용해 조건식을 검사하는 횟수를 줄일 것!! 

## if문 활용과 switch ~case문 

### If문 중첩 
- 어떤 조건을 검사하기 전에 선행조건이 있다면 if문 안에 if문을 넣어 사용합니다. 
- **why 중첩해서 사용?**
	- 선행조건이 있으면 불필요한 조건 검사 실행x
	- 선행조건이 없어도 실행 효율을 위해 의도적으로 중첩해서 사용이 가능합니다. 
		- ex)분할 정복 기법 
- **조금 더 알아보기**
	- if ~else if ~else도 if ~else + if ~else문이 중첩된 구조 

- ### Else 결합 문제 
- 주의!! 
	- if ~else문이 참일 때 실행문으로 기본if문이 쓰이면 반드시 **중괄호**가 필요!!! 
```c
#include <stdio.h>

  

int main(void)

{

int a = 10, b = 20;

  

if (a< 0)

if(b>0)//중첩if이지만 중괄호 생략 

{

printf("ok");

}

else//만약 중괄호 생략 시 중첩if문의 else구문으로 해석 따라서 아무것도 반환안함

{

printf("ok");

}

  

return 0;

}
```

### switch ~case 문 
- 기본 유형 
```c
switch( 조건식 )
{
case 상수식1:
	실행문1;
	break;
case 상수식2:
	실행문2;
	break;
case 상수식3:
	실행문3;
	break;
}
```
- 반드시 지켜야 할 규칙 
	- 조건식으로 정수만 사용 
	- 기본적으로 case는 **break**을 포함 
```c
#include <stdio.h>
int main(void)
{

int rank = 2, m= 0;
switch(rank)
{
case 1:

m = 300;

break;

case 2:

m = 200;

break;

case 3:

m = 100;

break;

default:

m = 10;

break;
}

printf("m: %d\n", m);

return 0;

}
```
- default는 상수식을 쓰지 않으며 생략이 가능합니다. 
- 만약 디폴트를 생략한 경우 rank와 일치하는 case의 상수가 없으면 바로 블록을 벗어나므로 블록 내의 어떤 문장도 실행이 되지 않습니다. 

- case/ default는 건너뛸 위치를 표시하는 레이블(Label)의 역할을 합니다. 

### break 생략 
- 필요에 따라 생략이 가능합니다. 

### switch ~else문 vs if문 
- switch ~else문은 정수 값에 따라 실행 문장을 선택하지 좋은 구조며 범위를 검사하는 경우에는 적합하지 않다.
