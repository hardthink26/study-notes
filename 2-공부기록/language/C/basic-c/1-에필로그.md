## 핵심 사항 
- **프로그램**: 일의 순서 나열 
- **컴파일**: 소스 코드를 **컴파일러**를 통해 컴퓨터가 이해하는 기계어로 만드는 과정 

- 컴파일의 과정 
	1. 전처리(preprocess)
		- 전처리 지시자에 따라 소스 코드를 가공하는 과정 
	2. 컴파일(compile)
		- 전처리가 끝난 파일을 컴파일을 하면 개체파일(object file)이 됨 
		- CPU가 해석 가능한 명령어(instruction)로 이루어진 기계어 파일 
	3. 링크 
		- object file에 startup code를 결합하는 과정
			- startup code는 프로그램 실행 전에 필요 사전 작업 진행 
		- main함수를 호출해 코드 실행
