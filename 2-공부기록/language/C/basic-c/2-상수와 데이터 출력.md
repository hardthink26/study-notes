## C 프로그램의 구조와 데이터 출력 방법 
- c 프로그램은 main 함수로 시작한다. 
	- main함수의 구조 
		- head + body 구성 
```c 
int main(void) // 머리 부분, function prototype이라고도 함 
{
	10 + 20; //중괄호 안을 body라고 함 
	return 0; //프로그램 종료 선언 
}
```
- printf function은 데이터를 화면 출력시에 사용 
```c 
int main(void) 
{ 
	printf("Be happy");
	return 0 ;
} 
```

### 제어 문자 
- 문자열 안에 포함시키면 그 기능에 따라 출력 형태가 바뀝니다. 
	- \n (개행, new line) 
	- \b (백스페이스, backspace): 한 칸 왼쪽으로 이동 
	- \r(캐리지 리턴, carriage return): 맨 앞으로 이동 
	- \a(알럿 경보, alert): 벨소리 

### 정수와 실수 출력- > 변환 문자 이용 
- 정수는 %d(decimal)을 이용합니다. 
	- `printf("%d", 10)`
- 실수는 %lf 
	- `printf("%.1lf", 2.33)`
		- lf앞 (.숫자) 는 그 숫자까지 출력합니다. 

## 2-2 상수와 데이터 출력 방법 

- 프로그램: 일의 순서를 적은 것 
- 데이터: 프로그램이 처리하는 대상 

### 정수 상수 표현법 

- 3가지 진법 즉 10진수, 8진수, 16진수로 표현 가능 

- **c에서 진법 표현하기 ** 
	- 8진수는 숫자 앞에 0(영), 16진수는 0x(영엑스)를 붙여 구분합니다. 

### 실수 상수 표현법 

- 크고 작은 숫자는 지수 표기법을 이용해 표기합니다. 
	- 소수점 앞에 0이 아닌 유효숫자 한 자리를 사용해 지수 형태로 바꾼 것을 **정규화 표현법**이라고 함 
```c 
#include <stdio.h>
int main(void)

{

printf("%.1lf\n", 1e6);//지수 형태의 실수를 소수점 형태로 출력 

printf("%.7lf\n", 3.14e-5);//소수점 이하 일곱 자리까지 출력 

printf("%.2e\n", 0.000314);// 소수점 형태로 소수점 이하 둘째 자리까지 출력 

return 0;

}
```

### 문자와 문자열 상수 표현법 

- 문자는 작은따옴표('), 문자열은 큰따옴표(")로 묶는다. 

```c
#include <stdio.h>
int main(void)
{

printf("%c\n", 'A');//문자 상수 출력 

printf("%s\n", "A");//문자열 상수 출력 

printf("%c는 %s입니다.", '1', "first");//문자와 문자열 함께 출력 

return 0;

}
```

### 상수가 컴파일된 후 비트 형태 

- 편집기에 코드 입력 시에 컴퓨터가 이해하는 형태의 아스키 코드값으로 저장 
- 코드가 컴파일 과정을 거쳐야 연산자는 명령어가 되고 상수는 연산이 가능한 형태로 바뀜 

### 정수 상수와 실수 상수의 컴파일 
- 정수 상수를 컴파일하면 4바이트, 실수 상수를 컴파일하면 8바이트가 됨 
- 실행 속도 차이를 유념하며 왠만하면 **정수 상수**사용을 권장 !!! 

### 문자 상수의 컴파일 
- 2진수 형태의 아스키 코드값으로 변환 
	- 예를 들어 'A'는 아스키 코드로 65로 변환 

### 정수 상수가 컴파일 된 후 비트 형태 

- **양수의 변환** 
	- 만약 값의 크기와 상관없이 데이터의 크기를 8비트로 만들려면 정수에 접미사 'LL', or 'll'을 붙여 사용 
		- 예시) `13ll`
- **음수의 변환** 
	- 음수는 절댓값을 2의 보수로 바꾸어 처리합니다. 
		- 2의 보수란? 
			- 2진수의 0과 1로 바꾼 후 1을 더한 값을 의미 
		- 왜 사용? 
			- 특별 과정 없이 양수와 음수를 바로 더해 사용이 가능하기 때문입니다. 

### 실수 상수가 컴파일된 후 비트 형태 
- 실수의 경우 제한된 데이터 크기에 수를 표현하기 위해 IEEE 754 표준을 따름 
	- 이 표준에는 single, double, quad가 존재 

- double 
	- 실수를 8바이트 표현, 즉 64비트를 사용 
	- **구성**
		- 부호비트: 가장 왼쪽 비트는 부호비트이며 양수는 0, 음수는 1이다. 
		- 지수부: 부호 비트 다음으로 11비트 차지 
		- 소수부: 나머지 52비트는 소수값을 의미
