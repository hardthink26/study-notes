## C 프로그램의 구조와 데이터 출력 방법 
- c 프로그램은 main 함수로 시작한다. 
	- main함수의 구조 
		- head + body 구성 
```c 
int main(void) // 머리 부분, function prototype이라고도 함 
{
	10 + 20; //중괄호 안을 body라고 함 
	return 0; //프로그램 종료 선언 
}
```
- printf function은 데이터를 화면 출력시에 사용 
```c 
int main(void) 
{ 
	printf("Be happy");
	return 0 ;
} 
```

### 제어 문자 
- 문자열 안에 포함시키면 그 기능에 따라 출력 형태가 바뀝니다. 
	- \n (개행, new line) 
	- \b (백스페이스, backspace): 한 칸 왼쪽으로 이동 
	- \r(캐리지 리턴, carriage return): 맨 앞으로 이동 
	- \a(알럿 경보, alert): 벨소리 

### 정수와 실수 출력- > 변환 문자 이용 
- 정수는 %d(decimal)을 이용합니다. 
	- `printf("%d", 10)`
- 실수는 %lf 
	- `printf("%.1lf", 2.33)`
		- lf앞 (.숫자) 는 그 숫자까지 출력합니다.
