- 일정 조건을 만족하는 동안 같은 실행문을 반복하는 것을 **반복문**이라고 합니다. 

### While문 
- 조건식을 먼저 검사하고 조건식이 참인 동안 실행문을 반복합니다. 
- **중괄호의 사용법과 들여쓰기** 
	- 모든 반복문은 실행문을 중괄호로 묶어서 반복할 부분을 표시힙나디. 
	- 불필요한 에러를 막기 위해서는 실행문의 개수와 상관없이 항상 중괄호로 반복할 부분을 명확히 표시!! 

### For문 
 - 실행문을 원하는 횟수만큼 반복할 때 사용합니다. 
 - **주의점**
	 - 초기식, 조건식, 증감식은 반복 횟수를 알기 쉽게 작성합니다. 
	 - 반복 횟수를 세는 변수를 반복문 안에서 바꾸지 않는 것이 좋습니다. 

### do ~while 문 
- 일단 반복할 문장을 수행한 후에 조건을 검사합니다. 
- 특징 
	- 조건식과 상관없이 반복할 문장을 최소 한 번은 실행합니다. 

## 반복문의 활용 
- 반복 안에 다시 반복이 이루어진 것을 **중첩 반복문** 혹은 **다중 반복문**이라고 합니다. 

### 중첩 반복문 
- 반복문 안에 실행할 문장으로 반복문이 포함된 것입니다. 
- **caution**
	- 각 반복문이 서로 독립적인 제어 변수를 사용해야 각각 원하는 횟수를 반복 가능 
- 중첩 반복문을 사용하려면 우선 반복되는 기본 문장과 규칙을 찾아야한다. 

### break & continue 분기문 
- break
	- 반복문 안에서 반복을 즉시 끝낼 때 사용합니다. 

###  break으로 무한 반복문 빠져나오기 

```c
while(1)
{
	printf("be happy\n");
}
return 0;
```
- 조건식에 사용된 1은 참을 의미하며 반복 과정에서 변하지 않으므로 출력문은 무한 출력 
```c
for(;;)
{
	printf("Be happy!');
}
return 0; 
```
- for문을 사용시에는 괄호 안에 세미콜론을 2개 사용합니다. 

### continue
- 반복문의 일부를 건너뜁니다. 
- 사용 시 다음 실행 위치가 반복문의 블록 끝이 됩니다.
