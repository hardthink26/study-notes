- 배열(array)
	- 같은 형태의 많은 데이터를 반복문으로 처리하기 위해서 메모리에 연속적으로 저장해 놓고 쪼개서 사용하는 방법 

### 배열의 선언
- 기본형 
	- `int ary[5]`
		- int형 변수는 크기가 4바이트이므로 5개를 연속으로 할당하면 총 20바이트입니다. 
- 배열의 나누어진 조각을 **배열 요소**라고 합니다. 

### 배열의 사용 
- 배열을 선언할 때 []안의 숫자의 의미는 각기 다른 의미를 가집니다. 
	- 선언할 때는 배열 요소의 전체 개수를 의미 
	- 사용할 때는 각 요소가 배열에서 몇 번째에 있는 지 의미 
		- 이 값을 **첨자**라고 합니다. 
### 배열 초기화 
- 배열도 변수와 마찬가지로 최초 할당된 저장공간에는 쓰레기 값이 저장되어 있습니다. 
- 그러므로 배열도 원하는 값을 가지려면 선언과 동시에 초기화 진행해야합니다. 
- ***초기화 방법1**
	- `int ary[5] = {1,2,3,4,5};`
- **초기화 방법2**
	- `int ary[5] = {1,2,3};`
		- 초깃값이 배열 요소의 개수보다 작은 경우 왼쪽부터 차례대로 초기화 진행하고 남은 배열 요소는 모두 0으로 채웁니다. 
- **초기화 방법3**
	- `int ary[1000] = {0};`
		- 자동 초기화 기능을 사용 가능합니다. 
- **초기화 방법 4**
	- `int ary[] = {1,2,3}; `
		- 컴파일러는 초깃값 개수만큼 배열 요소 개수를 정하고 저장 공간을 할당합니다. 
- **초기화 방법5**
	- `double ary[5] = {1.0, 2.1, 2.3, 4.5, 3.3}'`
	- `char ary[5] = {'a', 'p', 'c', 'e', 'g'};`
		- 각각의 자료형에 맞게 초기화하시면 됩니다. 
- 배열의 초기화는 선언 시 최초 한 번만 가능합니다. 그 이후에는 일일이 값을 대입해야 합니다. 

### 배열과 반복문 

### sizeof 연산자를 활용한 배열 처리 
- 배열 요소의 개수가 바뀌면 배열을 처리하는 반복문을 모두 수정해야 하는 부담이 있음
- 이 문제의 해결책으로 배열 요소의 개수를 직접 계산해 반복문에 사용하는 방법 
- 배열 요소의 개수 구하기 공식 
	- `sizeof(배열명)/sizeof(배열 요소)`
```c
#include <stdio.h>
int main(void)
{

int score[5];

int i;

int total = 0;

double avg;

int count ;

count = sizeof(score) / sizeof(score[0]);
for(i=0; i < count; i++)

{

scanf("%d", &score[i]);

}

for(i=0; i<count; i++)

{

total += score[i];

}

  

avg = total / (double)count;

for(i=0; i<count; i++)

{

printf("%5d", score[i]);

}

printf("\n");

printf("평균: %.1lf\n", avg);

return 0;

}
```
- 이렇게 구한 배열 요소의 개수를 각 반복문의 반복횟수로 세면, 나중에 배열 선언문에서 요소의 개수를 바꾸더라도 나머지 코드 수정할 필요 없음. 

## 문자를 저장하는 배열 
- 단어를 컴터가 처리하기 위해서는 메모리에 문자를 순서에 맞게 연속으로 저장 
- 모든 알파벳 문자는 한 바이트로 충분히 표현이 가능하니 char형 배열을 사용하는 것이 적당 

### char형 배열의 선언과 초기화 
- **반드시 기억!!**
	- 저장할 문자열 길이보다 최소한 하나 이상 크게 배열을 선언할 것 
	- why?
		- 널 문자(\0)를 저장하기 위해서입니다. 
### 널 문자의 용도 
- 초기화한 문자는 배열의 처음부터 차례로 저장되어 문자열을 만틉니다. 
- 이때 남는 배열 요소에는 자동으로 0이 채워집니다. 
	- 이렇게 저장된 0을 특별히 **널 문자**라고 부릅니다. 
		- 널 문자는 문자열의 끝을 표시하는 용도로 쓰입니다. 
 - char형 배열 선언 시 초기화하지 않은 경우 
	 - char배열 선언 시 초기화를 하면 남는 배열요소가 0으로 채워지므로 자동으로 문자열의 끝에 널 문자가 저장되나, 초기화되지 않은 상태에서 배열 요소에 문자를 직접 대입한다면 반드시 마지막 문자 다음에는 널 문자를 대입해야합니다.!!!!! 
- char형 배열 선언 시 주의할 점 
	- 배열의 크기는 최대한 넉넉하게 선언해야 합니다. 
	- 배열요소의 개수는 최소한 '문자열 길이 + 1'이어야 합니다. 

### 문자열 대입 
- char형 배열이 문자열을 저장하는 변수의 역할을 하므로 초기화된 이후에는 얼마든지 새로운 문자열을 저장할 수 있습니다. 
	- but, 일반 변수처럼 대입 연산자를 사용하는 것은 불가능합니다. 
	- 해결책: strcpy함수를 이용!!! 
	- 기본형 
		- `strcpy(저장될 배열명, 저장할 문자열);`

### 문자열 전용 입출력 함수: gets, puts 
- 왜 있을까? scanf쓰면 되는거 아님?
	- scanf함수는 중간에 빈칸이 있는 경우 빈칸 전까지만 입력합니다. 
```c
#include <stdio.h>
int main(void)
{

char str[80];

printf("문자열 입력: ");

gets(str);

puts("입력된 문자열: ");

puts(str);

return 0;
}
```
### 빈칸을 포함해 문자열을 입력하는 gets함수 
- gets함수는 문자열 입력 중간에 빈칸이나 탭 문자를 줄 수 있으며, 엔터를 누르기 전까지 전체를 하나의 문자열로 배열에 저장합니다. 
- **주의사항!!!**
	- gets함수는 입력한 배열의 크기를 검사하지 않으므로 배열의 크기보다 긴 문자열을 입력하면 배열을 벗어난 메모리 영역을 침범할 가능성이 있음 

### gets와 짝을 이뤄서 문자열을 출력하는 puts함수 
- printf와 기본적으로 동일 
- but, 문자열을 출력한 후 자동으로 줄을 바꿈
