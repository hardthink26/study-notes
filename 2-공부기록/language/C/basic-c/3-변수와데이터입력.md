- 프로그램에서 데이터를 메모리에 저장해 놓으면 필요시 꺼내 사용이 가능 
- 이때 변수 선언을 통해 저장공간을 확보 
- 변수는 데이터의 종류에 따라 각기 다른 형태를 사용 
	- 정수는 Int
	- 문자는 char 
	- 문자열은 char 배열을 사용 

### 변수 선언 방법 
- 타입: 데이터 종류에 맞게 자료형과 변수명을 나란히 적는다. 
	- 예시: `int a;` -> 정수를 저장할 공간을 a라 이름을 붙여 4바이트 할당을 의미 
- 변수 선언시 메모리에 저장공간이 생기며 처음 어떤 값이 있는지 모름 - > 메모리 공간은 재활용 됨 -> 프로그램 종료 시 메모리 공간을 반납하고 새로 실행된 프로그램이 그 공간 사용 
	- 이때 종료 프로그램이 어떤 값 남겨 놓았는지 모름 -> 새 프로그램에서 이 값의 의미를 **쓰레기값(garbage value)** 라고 함 
	- 따라서 반드시 초기화 과정이 필요 
		- 예시: `a = 10;` 
			- 프로그램에서 **=** 대입연산자라고 함 , 왼쪽은 저장 공간을 의미 

- 변수를 선언한 이후에는 변수명으로 값을 저장하고 연산, 출력이 가능 
```c 
#include <stdio.h>
int main(void)
{

int a;//int형 변수 a 선언 

int b, c ; //2개의 int형 변수 선언 

double da; //double형 변수 선언 

char ch;// char형 변수 선언 
a = 10 ;

b = a ;

c = a + 20 ;

da = 3.5;

ch = 'A' ;

printf("변수 a의 값: %d\n", a);

printf("변수 b의 값: %d\n", b);

printf("변수 c의 값: %d\n", c);

printf("변수 da의 값: %.1lf\n", da);

printf("변수 char의 값: %c\n", ch);

return 0;

}
```

### 변수 선언과 대입 규칙 
- **1. 중괄호의 블록안에 변수를 선언하며 선언한 위치부터 블록 끝까지 사용 가능** 
- **2. 변수의 자료형이 같으면 동시에 둘 이상의 변수를 선언 가능 
- **3. 대입 연산자는 연산자 왼쪽의 변수에 오른쪽의 값을 대입 
- **4. 변수는 대입 연산자 왼쪽에서는 저장 공간이 되고, 오른쪽에서는 값이 됩니다. 
	- i-value: 저장공간으로 사용하는 변수 
	- r-value: 값으로 사용되는 변수 

### 정수 자료형 
- 변수는 데이터를 저장하는 메모리의 공간이나 데이터 종류에 따라 다양한 형태를 가짐 -> **자료형 혹은 데이텨형**이라고 합니다. 
- 같은 정수형이어도 메모리 저장공간의 크기에 따라 char, short, int, long, long long 으로 구분 
	- 크기가 큰 자료형일수록 더 많은 범위의 값 저장이 가능하다. 
	- **범위** 
		- $-2^{비트 수 -1}~ 2^{비트 수 -1} -1 $
- **char**형은 크기가 1바이트로 -128~127까지 저장, 주로 문자 저장하는 용도로 쓰임 

- 각 자료형은 저장 값의 범위가 다르지만 출력할 때는 %d를 모두 사용 단, long형은 소문자 l을 붙여서 %ld로 출력하고 long long형은 두 개를 붙여 %lld로 출력 
 - **특별한 경우가 아니라면 int형을 사용하자!!** 
	 - int형은 연산의 기본 단위로 컴퓨터에서 가장 빠르게 연산 
- **long형은 큰 값을 저장할 때 사용합니다.** 

### unsigned 정수 자료형 
--- 
- 정수형은 보통 양수와 음수 모두 저장하지만, 양수만 저장하면 두 배 넓은 범위의 값을 저장합니다. 
- 따라서 나이와 같은 음수가 없는 데이터는 unsigned를 사용합니다. 
	- unsigned가 없으면 자동으로 signed로 선언됩니다. 
	- unsigned자료형을 사용할 때는 출력 시 변환 문자 사용에 주의 !! 
		- unsigned 변수에 큰 값 저장 시 %d로 출력 시 음수 출력 가능성 있음 
		- 음수를 저장하고 %u로 출력하면 양수 출력 가능성 있음 
```c 
int main(void)
{
unsigned int a;

a = 4294967295; //큰 양수 저장 

printf("%d\n", a) ;//%d로 출력 

a = -1 ; //음수 저장 

printf("%u", a); //%u로 출력 

return 0;
}
```
 - 저장값과 반대로 출력됩니다. 
	 - 두 정수가 메모리에 저장되는 형태는 같으나 printf함수가 데이터를 해석해서 보여 주는 방식이 다름 
		 - %d는 부호까지 생각해서 10진수로 출력, %u는 부호 없는  10진수로 출력하는 변환문자 
- **unsigned 자료형을 사용 시에는 항상 양수만 저장하고 %u로 출력** 

### 실수 자료형 
---
- 크기에 따라 float, double, long double로 구분하며, 값을 저장하는 범위가 다릅니다. 
- **유효 숫자의 개수에 집중 !! ** 
	-  **float형은 유효 숫자 7자리, double형은 15자리 범위 내의 값을 사용** 

- **정수형은 기본으로 사용하고 꼭 필요한 경우에만 실수형을 사용** 
- **실수형은 유효숫자가 많은 double형을 기본으로 사용합니다. 

### 문자열 저장 
- char 형을 배열 형태로 만들어 문자열을 저장합니다. 
- ` char 배열명(문자열 길이+1) = 문자열` 
	- why 문자열 길이 +1 ? 
		- 컴파일러가 문자열의 끝에 \0(널 문자)를 추가하기 때문입니다. 
	- 기본 자료형을 여러 개 묶어 사용하는 것을 배열(array)라고 합니다. 
- char 배열에 새로운 문자열을 저장하려면? 
	- char 배열에 초기화 이외에 문자열을 저장시에는 **strcpy**를 사용합니다. 

```c 
#include <stdio.h>
#include <string.h>
int main(void)
{

char fruit[20] = "strawberry";

printf("%s\n", fruit);

strcpy(fruit, "banana");

printf("%s\n", fruit);

return 0;

}
```

### const를 사용한 변수 

- const를 사용한 변수는 초기화된 값을 바꿀 수 없습니다. 

```c 
#include <stdio.h>
#include <string.h>
int main(void)
{

int income = 0 ;
double tax;
const double tax_rate = 0.12; 

income = 456;
tax = income * tax_rate ;
printf("세금은: %.1lf입니다.\n", tax);

return 0;
}
```
 - const를 사용하면 이후에는 값을 바꿀 수 없으므로 선언과 동시에 초기화를 진행하여야 합니다. 
- **왜 사용?** 
	- 복잡한 값에 의미 있는 이름을 붙일 수 있으며 값이 바뀌지 않음을 보장 가능 
- **주의** 
	- const는 보기에 상수처럼 쓰이지만 변수의 특성을 가지는 엄연한 변수!!! 

### 예약어와 식별자 

- 예약어(reserved word(key word))는 컴파일러와 사용 방법이 약속된 단어이며 , 식별자(identifier)는 필요에 따라 만들어 사용하는 단어업니다. 
	- `int(예약어) age(식별자) ` 
	- 식별자는 만들어 사용하는 단어이므로 중복되지 않는다면 어떤 것이든 사용 가능 
		- 알파벳 대문자, 소문자, 숫자, 밑줄 사용 
		- 숫자로 시작 x
		- 대문자와 소문자는 다른 식별자로 구분 
		- 예약어는 식별자로 사용 불가 

## 데이터 입력 

- 키보드서 타이핑하는 모든 내용은 문자로 인식 
- 따라서 입력한 데이터를 연산이 가능한 정수나 실수로 사용하려면 변환과정이 필요 
	- 이에 사용하는 것이 scanf입니다. 
		- 이 함수는 입력 문자들을 스캔해 원하는 형태의 데이터로 변환해줍니다. 

### scanf함수의 사용법 
- scanf함수는 키보드에서 입력한 값을 변수에 저장할 때 사용합니다.
