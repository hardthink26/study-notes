- 프로그램에서 데이터를 메모리에 저장해 놓으면 필요시 꺼내 사용이 가능 
- 이때 변수 선언을 통해 저장공간을 확보 
- 변수는 데이터의 종류에 따라 각기 다른 형태를 사용 
	- 정수는 Int
	- 문자는 char 
	- 문자열은 char 배열을 사용 

### 변수 선언 방법 
- 타입: 데이터 종류에 맞게 자료형과 변수명을 나란히 적는다. 
	- 예시: `int a;` -> 정수를 저장할 공간을 a라 이름을 붙여 4바이트 할당을 의미 
- 변수 선언시 메모리에 저장공간이 생기며 처음 어떤 값이 있는지 모름 - > 메모리 공간은 재활용 됨 -> 프로그램 종료 시 메모리 공간을 반납하고 새로 실행된 프로그램이 그 공간 사용 
	- 이때 종료 프로그램이 어떤 값 남겨 놓았는지 모름 -> 새 프로그램에서 이 값의 의미를 **쓰레기값(garbage value)** 라고 함 
	- 따라서 반드시 초기화 과정이 필요 
		- 예시: `a = 10;` 
			- 프로그램에서 **=** 대입연산자라고 함 , 왼쪽은 저장 공간을 의미 

- 변수를 선언한 이후에는 변수명으로 값을 저장하고 연산, 출력이 가능 
```c 
#include <stdio.h>
int main(void)
{

int a;//int형 변수 a 선언 

int b, c ; //2개의 int형 변수 선언 

double da; //double형 변수 선언 

char ch;// char형 변수 선언 
a = 10 ;

b = a ;

c = a + 20 ;

da = 3.5;

ch = 'A' ;

printf("변수 a의 값: %d\n", a);

printf("변수 b의 값: %d\n", b);

printf("변수 c의 값: %d\n", c);

printf("변수 da의 값: %.1lf\n", da);

printf("변수 char의 값: %c\n", ch);

return 0;

}
```
