- **함수**
	- 기능을 수행하는 코드 단위를 의미
	- 예시 
		- main함수
		- printf, scanf... 
			- 특정 기능을 미리 약속하고 프로그램에서 사용 할 수 있게  구현되어 있는 함수를 **표준 라이브러리 함수**라고 합니다. 
- 함수 제작 단계 
	1. 함수 정의 
		- 함수를 실제 코드로 만드는 것으로 함수의 기능을 구현 
	2. 함수 호출 
		- 함수 호출을 해야지 함수 사용 가능 
	3. 함수 선언 
		- 프로그램의 상단에서 어떤 함수를 사용할 것이라고 컴파일러에 정보를 주는 역할 

## 함수 정의 
- 고려할 것 
	- 함수의 기능에 맞는 이름은? 
	- 함수가 기능을 수행할 때 필요한 데이터는? 
	- 함수가 수행된 후 결과는? 
```c
#include <stdio.h>

int sum(int x, int y);

int main(void)

{

int a = 10, b = 20;

int result ;

result = sum(a, b);

printf("result : %d\n", result);

return 0;


}

  

int sum(int x, int y)

{

int temp;

temp = x + y ;

return temp;

}
```
- 함수를 함수 안에서 정의 안됩니다. 
	- sum함수는 main함수의 별도 구역에 제작 

### 함수 호출 
- 호출 시에는 이름을 사용하여 함수에 필요 데이터를 괄호 안에 넣어줌 

### 함수 반환 
- 함수 호출 시 현재 블럭 중단되고 함수 블록 실행 후 호출된 곳으로 반환되어 중단한 부분 재실행 
- 컴파일러는 함수를 호출 시에 반환값을 저장할 공간을 미리 준비합니다. 
	- 이 공간은 컴파일러가 별도로 확보하는 공간이며 별도로 식별할 이름이 없으므로 계속 사용x
	- 하지만, 저장된 반환값을 대입 연산으로 다른 변수에 복사하거나 수식에 바로 사용 가능 

### 함수 선언 
- 컴파일러가 새로 만든 함수를 인식할 수 있도록 알리는 역할을 합니다. 
- 방법 
	- 함수 원형에 세미콜론 붙임 
	- 매개변수 이름은 생략이 가능합니다. 
- 함수 정의하는데 왜 선언함? 
	- 함수 선언에서 반환값의 형태를 확인합니다. 
		- 컴파일러는 컴파일시 함수를 호출한 자리에 반환값과 같은 형태의 저장 공간을 준비 
		- 선언을 통해 반환형을 미리 컴파일러에 알릴 필요가 있음 
	- 함수의 호출 형식에 문제가 없는지 검사 
		- 함수 선언문에는 매개변수의 개수와 형태에 대한 정보가 있으므로 호출할 때 정확한 값을 주는 지 검사 가능 
- 함수 선언이 없으면 함수 정의는 함수 호출 이전에 있어야 합니다. 
	- **필요한 함수를 main함수 밑에 차례로 만들고 main함수 앞에는 모든 함수를 선언해 함수의 종류와 원형을 한눈에 파악하고 자유롭게 호출할 수 있도록 작성이 권고!!** 

## 여러 가지 함수 유형 
### 매개변수가 없는 함수 
- 호출할 함수로부터 값을 받을 필요가 없다면 매개변수도 필요 없습니다. 
	- 이때 매개변수의 자리에는 void를 사용합니다. 
```c
#include <stdio.h>

int get_num(void);

int main(void)
{

int result;

result = get_num();

printf("반환값: %d\n", result);

return 0;

}

int get_num(void)
{

int num;

printf("양수 입력: ");

scanf("%d", &num);

return num;
}
```
- 괄호 안에 void를 넣어 매개변수가 없음을 표시합니다. 

### 반환값이 없는 함수 
- 함수는 기능에 따라 형태가 결정됩니다. 데이터를 받아서 단지 화면에 출력하는 함수라면 반환값이 필요없습니다. 
```c
void print_char(char, int);
int main(void)

{

print_char('@', 5);

return 0;

}

void print_char(char ch, int count)
{

int i;

for (i=0; i<count; i++)

{
printf("%c", ch);
}
return ;
}
```
- 반환형의 자리에 void를 사용 
- return 문을 생략하는 것도 가능합니다. 
	- 자동으로 함수의 코드를 모두 수행하면 호출한 곳으로 자동으로 돌아갑니다. 
- **참고** 
	- 반환형이 void인 함수는 컴파일러가 반환값이 없다고 가정해 호출한 위치에 반환값을 저장할 공간을 준비하지 않습니다. 

### 매개변수와 반환값이 모든 없는 함수 
```c
#include <stdio.h>

void print_line(void);

int main(void)
{

print_line();

printf("학번 이름 전공 학점\n");

print_line();

return 0;

}

void print_line(void)
{

int i;

for(i=0; i< 50; i++)
{
printf("-");
}
printf("\n");
}
```

### 재귀호출과 반복문의 차이점 
- 재귀호출 함수는 직전에 호출한 곳으로 돌아간다. 
- **재귀호출 함수는 경우에 따라 복잡한 반복문을 간단히 표현이 가능하나 코드 읽기가 쉽지 않고 반복 호출되면서 메모리를 사용하므로 제한적으로 써라**
