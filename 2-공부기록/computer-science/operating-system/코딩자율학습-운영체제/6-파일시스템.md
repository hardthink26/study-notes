## 파일 시스템 개요 
- 파일 시스템은 컴퓨터에서 데이터를 저장하고 관리하는 방법을 정의한 시스템입니다. 
- 파일 시스템은 파일(문서, 이미지, 비디오, 프로그램 등)을 저장하며, 사용자가 파일에 쉽게 접근할 수 있도록 합니다. 
## 파일과 메타데이터 
- 파일 시스템은 파일과 메타데이터를 저장하고 관리합니다. 
### 파일 
- 컴퓨터에서 데이터를 저장하고 관리하는 기본 단위입니다. 
- 파일에는 다양한 형태의 정보를 담을 수 있습니다. 
	- 텍스트/문서 파일 
		- 일반 텍스트나 문서를 저장합니다. 
		- .txt, .docs, .pdf ... 
	- 이미지 파일 
		- 사진이나 그림을 저장 
		- .jpg, .png, .gif
	- 비디오 파일 
		- 동영상을 저장 
		- .mp4, .avi, .mkv
	- 오디오 파일 
		- .mp3, .wav, .aac
	- 프로그램 파일 
		- 소프트웨어 실행 파일이나 소스 코드를 포함합니다.
		- .exe, .dll, .py
- **구성**
	- 각 파일은 컴퓨터에서 고유한 이름과 형식을 가짐 이를 **파일 이름** 과 **파일 확장자** 라고 합니다. 
		- 확장자는 작업의 유형을 나타내며, 운영체제는 이를 기반으로 해당 파일을 처리하기에 적합한 프로그램을 연결합니다. 
- 파일은 컴퓨터의 보조 기억 장치(HHD, SSD, USB 드라이버 등)에 저장하고, 파일 시스템이 이를 관리합니다. 
### 메타데이터 
- 파일 자체가 아닌 파일에 대한 추가 정보를 담고 있는 데이터입니다. 
- 파일이 어떤 것인지 설명해 주는 정보 
- **구성 요소**
	- 사용자 ID
		- 파일을 만든 사람이나 사용자 정보 
	- 파일 유형 
		- 파일의 형식(문서, 이미지, 음악 등)
	- 파일 크기 
		- 파일이 차지하는 용량 
	- 저장 위치 
		- 파일을 저장하는 경로 
	- 오프셋 정보 
		- 파일 내 데이터의 위치 
	- 버퍼 정보 
		- 데이터를 임시로 저장한 공간에 대한 정보 
	- 시간 정보 
		- 파일의 생성(수정/접근 시간)
- 메타데이터를 파일 시스템에 파일과 별도로 
- 파일 시스템은 메타데이터를 기반으로 파일의 위치와 속성을 관리합니다. 

## 디렉터리와 경로 

### 디렉터리 
- 파일을 체계적으로 그룹화해 관리하는 논리적인 구조입니다. 
- 디렉터리 안에 같은 이름을 가진 하위 디렉터리는 존재할 수 없습니다. 
- **구조**
	- 트리 구조를 기반으로 계층적으로 구성
	- 최상위 디렉터리는 루트 디렉터리로, 모든 파일과 디렉터리의 시작점입니다. 
	- 루트 디렉터리에는 여러 하위 디렉터리(subdirectory)에 파일을 포함 가능 
	- [[구조 그림 넣기 ]]
- 파일 시스템은 디렉터리와 파일을 계층적으로 관리합니다. 
	- 이러한 계층 구조는 사용자가 파일이나 디렉터리를 체계적으로 관리하고 필요한 데이터를 빠르게 탐색 가능하게 합니다.
