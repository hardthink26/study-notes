# 스케줄링이란

CPU와 시스템 자원을 여러 프로세스에 효율적으로 분배하는 방법입니다.

## 설계 목적

- **공평성과 예측성**
    - 모든 프로세스가 공정하게 CPU 시간을 배분받고, 각 프로세스의 수행 시간을 예측 할 수 있도록 보장
- **자원 활용 극대화**
    - 시간당 처리되는 프로세스의 수(처리량)를 증가시키고, CPU가 유휴상태(idle)가 되지 않도록 유지
- **우선순위 기반 처리**
    - 실시간 프로세스의 중요한 작업을 우선적으로 실행해 시스템이 더욱 효과적으로 작동하도록 관리
- **응답 시간 최소화**
    - 특정 프로세스가 과도하게 대기하지 않도록 관리해 시스템의 전반적인 응답 속도를 개선합니다.

## 스케줄링 구분

- **CPU 스케줄링**
    - 프로세스가 CPU를 사용할 순서를 결정하는 알고리즘
- **입출력 스케줄링**
    - 디스크를 포함한 입출력 장치의 사용 순서를 결정하는 알고리즘

# 스케줄링 알고리즘

- 기준은 **우선순위 적용 방식**과 **선점 여부**입니다.

## 선점형 스케줄링

- 더 높은 우선순위를 가진 프로세스가 도착하면 실행 중인 프로세스를 중단하고 CPU를 할당하는 방식
- **선점하는 경우**
    - 더 높은 우선순위를 가진 프로세스가 도착하면 실행 중인 프로세스를 중단
    - 프로세스가 CPU를 일정 시간 동안만 사용하고, 시간이 종료되면 다음 프로세스 실행
    - 프로세스가 입출력 작업을 수행하거나 대기 상태로 전환하면 다른 프로세스가 CPU차지
