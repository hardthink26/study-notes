# Study Notes & dev logs 
이론 학습(study-notes)과 실전 구현(개발일지)을 기록하는 공간입니다. 

## 개발과 이론은 why 중심으로 학습합니다.
책을 프로젝트 중심으로 진행하되, 스스로 설계하고 검증하는 능력을 기르는 것을 우선시합니다.

### 1. 실전 개발 
1. **흐름 파악**: 한번에 이해 가능한 범위의 챕터와 코드를 읽고 노트에 흐름 및 특이 문법을 기록합니다.
2. **구현**: 30분 시간을 정하고 공식 문서만을 이용하여 코드를 스스로 작성합니다.
3. **코드 비교**: 구현 이후 책을 다시 펼쳐 저자의 코드와 비교하며 설계 차이와 예외 처리를 분석합니다.
4. **기록 및 커밋**: 에러 사항과 깨달음을 정리하여 매일 GitHub에 커밋합니다.

### 2. 이론 공부 - 백지 복습(study-notes)
강의 및 책을 통해 얻은 지식을 내재화하기 위한 복습법을 진행합니다. 
1. **백지 설명**: 학습한 지식을 바탕으로, 교수가 되어 학생들을 이해시킨다는 가정하에 정의부터 응용까지 백지에 직접 설명을 합니다.
2. **논리 비약**: 설명이 막히거나 논리가 허술한 지점은 다시 책과 강의를 이용하여 빈틈을 메웁니다.

## 디렉터리 구조 
- **개발일지** : flask 웹 애플리케이션 구현 과정 및 트러블슈팅 기록
- **study-notes** : python, network, operating system, computer structure 원리 탐구
- **technical-writing** : 기술 문서화 연습
